JavaScript-програма — це текстовий файл або рядок коду, що виконується рушієм. У браузері рушій запускається через тег <script>. Спосіб підключення скрипта безпосередньо впливає на порядок і час його виконання.

Тег <script>

Тег <script> може містити код безпосередньо або посилатися на зовнішній файл через атрибут src.

HTML
<!-- Інлайн-скрипт -->
<script>
  console.log('Hello from inline script');
</script>

<!-- Зовнішній файл -->
<script src="app.js"></script>

<!-- Якщо вказано src, вміст тега ігнорується -->
<script src="app.js">
  console.log('Цей код НЕ виконається'); // ігнорується
</script>
Зовнішні файли — стандарт

Зовнішні .js файли кешуються браузером. Після першого завантаження повторні сторінки отримують скрипт з кешу без мережевого запиту. Інлайн-скрипти кешуватися не можуть.

Порядок виконання: класична поведінка

За замовчуванням тег <script> блокує парсинг HTML. Браузер зупиняє побудову DOM, завантажує і виконує скрипт, потім продовжує парсинг. Саме тому класично скрипти розміщують перед </body> — щоб не блокувати відображення вмісту.

HTML
<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <title>Моя сторінка</title>
  <!-- Скрипт у head блокує рендеринг до завантаження -->
  <!-- script src="heavy.js"></script -->
</head>
<body>
  <h1>Вміст сторінки</h1>

  <!-- Класичне розміщення: перед закриваючим body -->
  <script src="app.js"></script>
</body>
</html>

Атрибути async і defer

Сучасний підхід — розміщувати скрипти в <head> з атрибутами async або defer. Обидва дозволяють браузеру завантажувати скрипт паралельно з парсингом HTML, але відрізняються моментом виконання.

АтрибутЗавантаженняВиконанняПорядок
немаєСинхронне, блокує парсингВідразу після завантаженняПо порядку в HTML
deferПаралельно з парсингомПісля завершення парсингу DOMПо порядку в HTML
asyncПаралельно з парсингомОдразу після завантаження (блокує)Не гарантований
HTML
<head>
  <!-- defer: виконається після побудови DOM, зберігає порядок -->
  <script defer src="framework.js"></script>
  <script defer src="app.js"></script>
  <!-- app.js гарантовано виконається після framework.js -->

  <!-- async: для незалежних скриптів (аналітика, реклама) -->
  <script async src="analytics.js"></script>
</head>
Рекомендація: defer за замовчуванням

Використовуйте defer для основних скриптів застосунку — він зберігає порядок залежностей і не блокує рендеринг. async — лише для незалежних скриптів без залежностей від DOM або інших скриптів.

type="module"

Атрибут type="module" переводить скрипт у режим ES-модуля. Це змінює кілька важливих речей:

  • Автоматично застосовується use strict
  • Кожен модуль має власну область видимості (змінні не потрапляють у globalThis)
  • Доступні import / export
  • Виконується із затримкою як defer за замовчуванням
  • Один і той самий модуль завантажується лише раз, навіть якщо підключений кілька разів
HTML
<script type="module" src="main.js"></script>
JavaScript — main.js
import { formatDate } from './utils.js';

const today = formatDate(new Date());
console.log(today);
Модулі потребують сервера

Модулі завантажуються через HTTP(S). Відкриття HTML-файлу напряму (file://) призведе до CORS-помилки. Використовуйте локальний сервер: npx serve . або Live Server у VS Code.

Перший скрипт

HTML
<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <title>Перший скрипт</title>
  <script defer src="main.js"></script>
</head>
<body>
  <p id="output"></p>
</body>
</html>
JavaScript — main.js
// defer гарантує, що DOM вже побудований
const output = document.getElementById('output');
output.textContent = 'Привіт, світ!';
console.log('Скрипт виконано');

Підсумок

  • Тег <script> без атрибутів блокує парсинг HTML під час завантаження і виконання.
  • defer — завантаження паралельно, виконання після DOM, порядок збережено. Стандарт для основних скриптів.
  • async — завантаження паралельно, виконання одразу, порядок не гарантований. Для незалежних скриптів.
  • type="module" — ES-модуль зі своєю областю видимості, import/export, автоматичним use strict і поведінкою defer.
  • Якщо задано src, вміст тега ігнорується.
