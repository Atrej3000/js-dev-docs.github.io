Функціональний вираз (function expression) — це функція, створена як частина виразу і присвоєна змінній або передана як аргумент. На відміну від function declaration, він не піднімається.

Синтаксис

JavaScript
// Function expression — присвоєння функції змінній
const square = function(n) {
  return n * n;
};

console.log(square(4)); // 16
console.log(typeof square); // "function"

// На відміну від declaration — не піднімається (TDZ для const)
// console.log(cube(3)); // ReferenceError
const cube = function(n) { return n ** 3; };
console.log(cube(3)); // 27

Callback-функції

Функція, передана як аргумент іншій функції для подальшого виклику.

JavaScript
// Анонімний callback
const numbers = [3, 1, 4, 1, 5, 9];
const sorted = numbers.sort(function(a, b) { return a - b; });
console.log(sorted); // [1, 1, 3, 4, 5, 9]

// Іменований callback (кращий стек викликів при помилках)
function compareAsc(a, b) { return a - b; }
const sorted2 = numbers.sort(compareAsc);

// setTimeout — типовий кейс для callback
setTimeout(function() {
  console.log('1 секунда пройшла');
}, 1000);

Named Function Expression (NFE)

Функціональний вираз може мати ім'я. Це ім'я видиме лише всередині самої функції — корисно для рекурсії і відлагодження.

JavaScript
const factorial = function fact(n) {
  if (n <= 1) return 1;
  return n * fact(n - 1); // ім'я 'fact' доступне всередині
};

console.log(factorial(5)); // 120
// console.log(fact(5));   // ReferenceError — 'fact' не видиме зовні

// Переваги NFE: ім'я у стеку викликів при помилці
const processData = function processData(data) {
  // У stack trace буде "processData" замість "anonymous"
  if (!data) throw new Error('No data');
};

IIFE — Immediately Invoked Function Expression

Функція, що викликається одразу після оголошення. Створює ізольований scope.

JavaScript
// Класичний IIFE (дужки обов'язкові — без них SyntaxError)
(function() {
  const privateVar = 'секрет';
  console.log(privateVar);
})();

// IIFE зі стрілковою функцією
(() => {
  const config = initConfig();
  applyConfig(config);
})();

// IIFE з поверненням значення
const appVersion = (function() {
  const major = 2, minor = 5;
  return `${major}.${minor}`;
})();

// Сучасна альтернатива IIFE — блок зі let/const або ES-модулі
{
  const privateVar = 'секрет'; // видима лише в цьому блоці
}

Підсумок

  • Function expression не піднімається — виклик до оголошення викидає ReferenceError.
  • Для умовного оголошення функції — завжди expression.
  • NFE: ім'я видиме лише всередині — для рекурсії і кращих stack trace.
  • Callback — функція як аргумент. Іменований callback кращий за анонімний для відлагодження.
  • IIFE — ізоляція scope. У сучасному коді замінюється ES-модулями або блоками.
