Програма на JavaScript складається з інструкцій. Інструкції розділяються крапкою з комою. Крім коду, файл може містити коментарі. Розуміння правил розбору тексту рушієм запобігає класу важко відтворюваних помилок.

Інструкції

Інструкція — синтаксична конструкція, що виконує певну дію. Кілька інструкцій в одному рядку розділяються крапкою з комою:

JavaScript
// Одна інструкція на рядок — стандарт читабельності
const greeting = 'Hello';
console.log(greeting);

// Дозволено, але не рекомендовано: кілька на рядок
const x = 1; const y = 2; console.log(x + y);

Крапка з комою

Крапка з комою завершує інструкцію. Це явне позначення межі між інструкціями і є рекомендованою практикою для більшості стилів коду.

Автоматична вставка крапки з комою (ASI)

Automatic Semicolon Insertion (ASI) — механізм специфікації ECMAScript, за яким рушій вставляє крапку з комою в певних місцях, де її немає у вихідному коді. Це дозволяє писати код без явних крапок з комою, але механізм має нетривіальні винятки.

JavaScript
// ASI вставляє крапку з комою — цей код працює
const a = 1
const b = 2
console.log(a + b) // 3

Небезпечні випадки ASI

ASI не вставляє крапку з комою, якщо рядок може бути продовженням попереднього. Найпоширеніша пастка — рядок, що починається з (, [ або шаблонного літерала:

JavaScript
// ПАСТКА: ASI не вставляє крапку з комою перед (
const value = 1
(function() { console.log('IIFE') })()
// Рушій бачить: const value = 1(function(){...})()
// TypeError: 1 is not a function

// РІШЕННЯ: явна крапка з комою
const value = 1;
(function() { console.log('IIFE') })();

// Інша пастка: рядок починається з [
const arr = [1, 2, 3]
[0, 1].forEach(i => console.log(arr[i]))
// Рушій: const arr = [1,2,3][0,1].forEach(...)
// TypeError: не масив

// Захисна крапка з комою на початку (стиль деяких мінімалістичних кодестайлів)
;[0, 1].forEach(i => console.log(arr[i]))
Рекомендація

Завжди ставте крапку з комою явно. ASI — не заміна явній семантиці, а механізм сумісності. Linter (ESLint) з правилом semi автоматично контролює це.

Коментарі

Коментарі не виконуються рушієм. Вони існують для людей, які читають код.

JavaScript
// Однорядковий коментар — від // до кінця рядка

/*
  Багаторядковий коментар.
  Використовується для блоків тексту або тимчасового
  відключення великого фрагмента коду.
*/

/**
 * JSDoc-коментар — документація для функцій та класів.
 * Підтримується редакторами для IntelliSense.
 *
 * @param {number} amount - Сума платежу в гривнях
 * @param {string} currency - Код валюти (ISO 4217)
 * @returns {number} Конвертована сума
 */
function convertCurrency(amount, currency) {
  // реалізація
}

Що коментувати, а що — ні

Коментар пояснює чому, а не що. Код сам описує що він робить. Коментар додає контекст, недоступний з коду.

JavaScript
// ПОГАНИЙ коментар: переказує код
// Збільшуємо лічильник на 1
count++;

// ХОРОШИЙ коментар: пояснює причину
// Зсув на 1 компенсує 0-базовану індексацію API (документація v3, §4.2)
const pageIndex = currentPage - 1;

// ХОРОШИЙ коментар: попереджає про неочевидне
// parseInt без основи може давати вісімковий результат у старих браузерах
// тому завжди вказуємо 10
const parsed = parseInt(input, 10);

Edge cases

ASI після return

Одна з найвідоміших пасток: рядковий перенос після return вставляє крапку з комою — функція повертає undefined.

JavaScript
// АНТИПАТЕРН: ASI після return
function getConfig() {
  return          // ← ASI вставляє ; тут
  {               // цей об'єкт НІКОЛИ не повертається
    timeout: 5000
  };
}
console.log(getConfig()); // undefined

// ПРАВИЛЬНО: дужка на тому ж рядку
function getConfig() {
  return {
    timeout: 5000
  };
}
console.log(getConfig()); // { timeout: 5000 }
return на окремому рядку

ASI після return, throw, break, continue є джерелом реальних продакшен-помилок. Ніколи не переносьте вираз, що повертається, на новий рядок без відкриваючої дужки.

Підсумок

  • Інструкції завершуються крапкою з комою. Явна крапка з комою — надійніший стиль.
  • ASI автоматично вставляє крапку з комою в більшості місць, але має нетривіальні винятки: рядки, що починаються з (, [, шаблонних літералів.
  • Перенос рядка після return вставляє ; — функція поверне undefined. Відкриваюча дужка завжди на тому ж рядку, що й return.
  • // — однорядковий коментар, /* */ — блоковий, /** */ — JSDoc.
  • Коментар пояснює «чому», а не «що».
