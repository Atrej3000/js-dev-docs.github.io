Ця стаття — зведений довідник ключових правил і особливостей JavaScript, розглянутих у розділі «Основи». Використовуйте її для повторення і як швидкий reference.

Структура коду

  • Інструкції завершуються ;. ASI вставляє крапку з комою автоматично, але має небезпечні винятки.
  • Рядки після return, throw, break вставляють ; — значення завжди на тому ж рядку що й ключове слово.
  • Рядки що починаються з (, [ або шаблонного літерала не отримують автоматичного ;.

Змінні

  • const за замовчуванням, let — коли потрібне переприсвоєння, var — тільки legacy.
  • let/const: блокова область видимості, TDZ до рядка оголошення.
  • var: функціональна область видимості, підіймається з ініціалізацією undefined.
  • for з let — нова прив'язка на кожну ітерацію.

Типи даних

  • 8 типів: Number, String, Boolean, null, undefined, Symbol, BigInt (примітиви) + Object.
  • typeof null === "object" — баг. Перевіряйте через === null.
  • typeof [] === "object". Перевіряйте через Array.isArray().
  • NaN !== NaN. Перевіряйте через Number.isNaN().
  • Примітиви — за значенням. Object — за посиланням.

Перетворення типів

JavaScript
// Числове: null→0, undefined→NaN, true→1, false→0, ""→0, "3px"→NaN
// Рядкове: null→"null", undefined→"undefined", []→"", {}→"[object Object]"
// Булеве: falsy = false, 0, -0, 0n, "", null, undefined, NaN

// + з рядком → конкатенація; інші арифм. оператори → числове перетворення
"5" + 2   // "52"
"5" - 2   // 3
"5" * "2" // 10

Оператори і порівняння

  • Використовуйте === і !== завжди. Виняток: value == null для перевірки на null і undefined.
  • || — перший truthy або останній. && — перший falsy або останній.
  • ?? — повертає правий тільки при null/undefined ліворуч.
  • ** — права асоціативність: 2 ** 3 ** 2 = 512.

Цикли

  • for...of — для iterable (масиви, рядки, Map, Set).
  • for...in — для ключів об'єкта (з hasOwn). Не для масивів.
  • break — вихід. continue — наступна ітерація. З міткою — для вкладених циклів.

Функції

  • Function declaration піднімається повністю. Function expression — ні.
  • Дефолтні параметри спрацьовують лише для undefined, не для null.
  • Функція без return повертає undefined.
  • Стрілкові функції: лексичний this, немає arguments, не можна як конструктор і метод об'єкта.
  • Для методів об'єкта — завжди звичайна функція або shorthand method() {}.

Що далі

Розділ «Основи JavaScript» завершено. Наступний розділ — Якість коду — охоплює дебаґінг, стандарти оформлення, JSDoc, автоматичне тестування і поліфіли.

JavaScript — Quick reference
// Змінні
const MAX = 100;          // незмінна прив'язка
let count = 0;            // мутабельна

// Типи
typeof null    // "object" (баг)
typeof []      // "object"
Array.isArray([]) // true — правильна перевірка
NaN === NaN   // false
Number.isNaN(NaN) // true

// Порівняння
=== // суворе — завжди
==  // тільки value == null (null + undefined)

// Логічні
a || b  // перший truthy або b
a && b  // перший falsy або b
a ?? b  // b лише якщо a є null/undefined

// Функції
function f() {}    // declaration — hoisting
const f = () => {} // arrow — лексичний this, немає arguments
const f = function named() {} // NFE — ім'я всередині

// Цикли
for (const v of iterable) {} // масиви, рядки, Map, Set
for (const k in obj) {}      // ключі об'єкта (+ hasOwn перевірка)
