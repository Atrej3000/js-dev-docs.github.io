Умовне розгалуження дозволяє виконувати різні блоки коду залежно від значення виразу. JavaScript надає інструкцію if/else для блокового розгалуження і тернарний оператор ? для виразів.

Інструкція if

Умова перетворюється на булеве значення (ToBoolean). Якщо true — виконується блок. Фігурні дужки необов'язкові для одного рядка, але рекомендовані завжди.

JavaScript
const score = 75;

// Базова форма
if (score >= 60) {
  console.log('Зараховано');
}

// if / else
if (score >= 60) {
  console.log('Зараховано');
} else {
  console.log('Не зараховано');
}

// if / else if / else — ланцюг умов
if (score >= 90) {
  console.log('Відмінно');
} else if (score >= 75) {
  console.log('Добре');
} else if (score >= 60) {
  console.log('Задовільно');
} else {
  console.log('Незадовільно');
}
Завжди використовуйте фігурні дужки

Код без дужок дозволений, але небезпечний при додаванні рядків. Відсутність дужок — поширена причина помилок. Єдиний виняток — guard clause (ранній вихід) в одному рядку.

Truthy/falsy в умовах

JavaScript
const username = '';
const items = [];
const config = null;

// Порожній рядок — falsy
if (username) {
  console.log('є ім\'я'); // НЕ виконується
}

// АНТИПАТЕРН: порожній масив — truthy!
if (items) {
  console.log('є елементи'); // виконується навіть для []
}
// ПРАВИЛЬНО:
if (items.length > 0) {
  console.log('є елементи');
}

// Перевірка на null/undefined
if (config !== null && config !== undefined) {
  // явна перевірка
}
if (config != null) {
  // скорочена форма — спрацює для null і undefined
}

Тернарний оператор ?

Єдиний тернарний оператор JavaScript: умова ? значення_якщо_true : значення_якщо_false. Є виразом — повертає значення, тому може використовуватись у присвоєнні, аргументі функції, шаблонному літералі.

JavaScript
const age = 20;

// Базове використання
const status = age >= 18 ? 'повнолітній' : 'неповнолітній';
console.log(status); // "повнолітній"

// У шаблонному літералі
console.log(`Статус: ${age >= 18 ? 'OK' : 'відмовлено'}`);

// Як аргумент функції
fetch(isAdmin ? '/api/admin' : '/api/user');

// Ланцюг тернарних операторів — читабельний при правильному відступі
const grade =
  score >= 90 ? 'A' :
  score >= 75 ? 'B' :
  score >= 60 ? 'C' :
  'F';

// Тернарний оператор НЕ замінює if для складної логіки
// АНТИПАТЕРН: виконання побічних ефектів у тернарному
isAdmin
  ? (log('admin action'), performAdminAction()) // погано
  : performUserAction();
// Використовуйте if/else для побічних ефектів

Ранній вихід (Guard Clause)

Патерн guard clause — перевірка передумов на початку функції з раннім поверненням. Зменшує вкладеність і покращує читабельність.

JavaScript
// АНТИПАТЕРН: глибока вкладеність
function processOrder(order) {
  if (order) {
    if (order.items) {
      if (order.items.length > 0) {
        if (order.payment) {
          return fulfill(order);
        }
      }
    }
  }
  return null;
}

// КРАЩЕ: guard clauses — ранній вихід
function processOrder(order) {
  if (!order) return null;
  if (!order.items || order.items.length === 0) return null;
  if (!order.payment) return null;

  return fulfill(order);  // основна логіка без вкладеності
}

if/else vs switch

Інструкція if/else перевіряє довільні вирази. switch перевіряє одне значення на рівність (===) кільком варіантам. Вибір між ними — питання читабельності.

JavaScript
const method = 'GET';

// if/else — для різних виразів або діапазонів
if (method === 'GET' || method === 'HEAD') {
  handleRead();
} else if (method === 'POST' || method === 'PUT') {
  handleWrite();
} else {
  handleOther();
}

// switch — для одного значення і конкретних варіантів
switch (method) {
  case 'GET':
  case 'HEAD':
    handleRead();
    break;
  case 'POST':
  case 'PUT':
    handleWrite();
    break;
  default:
    handleOther();
}

// Lookup object — часто краще за switch для простого маппінгу
const handlers = {
  GET: handleRead,
  HEAD: handleRead,
  POST: handleWrite,
  PUT: handleWrite,
};
const handler = handlers[method] ?? handleOther;
handler();

Edge cases

JavaScript
// Присвоєння в умові — легальне, але небезпечне
let data;
if (data = fetchData()) { // присвоєння, а не порівняння!
  process(data);
}
// ESLint попереджає про це. Якщо навмисно — використовуйте подвійні дужки:
if ((data = fetchData())) { /* явна ознака навмисності */ }

// Пустий else — не потрібен
if (condition) {
  doSomething();
} else {
  // нічого
}
// Просто:
if (condition) {
  doSomething();
}

// Умова-вираз повертає значення
const x = (1 > 0) ? 'yes' : 'no'; // "yes"

Підсумок

  • if (expr) перетворює вираз на Boolean (ToBoolean).
  • Завжди використовуйте фігурні дужки — навіть для одного рядка.
  • Порожній масив [] та об'єкт {} — truthy. Перевіряйте .length або вміст, а не сам контейнер.
  • Тернарний ? — вираз, повертає значення. Для побічних ефектів використовуйте if/else.
  • Guard clause (ранній вихід) — зменшує вкладеність і покращує читабельність.
  • Для простого маппінгу значень lookup object часто читабельніший за switch.
