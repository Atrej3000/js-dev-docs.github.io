switch порівнює вираз з кількома значеннями через строге рівність (===) і виконує відповідний блок. Використовується коли одна змінна перевіряється на рівність кільком конкретним значенням.

Синтаксис

JavaScript
const status = 'active';

switch (status) {
  case 'active':
    console.log('Активний');
    break;
  case 'inactive':
    console.log('Неактивний');
    break;
  case 'banned':
    console.log('Заблокований');
    break;
  default:
    console.log('Невідомий статус');
}
switch використовує === без перетворень

switch (x) порівнює через строгу рівність. switch ('1') з case 1: — не збігається, бо '1' !== 1.

Fall-through

Якщо break відсутній — виконання «проваллюється» в наступний case. Це може бути навмисним (групування) або помилкою.

JavaScript
// ПОМИЛКА: забутий break
switch (day) {
  case 'Monday':
    console.log('Початок тижня');
    // break відсутній — провалюється в Tuesday
  case 'Tuesday':
    console.log('Вівторок або понеділок без break');
    break;
}

// НАВМИСНЕ fall-through: групування кількох case
switch (day) {
  case 'Saturday':
  case 'Sunday':
    console.log('Вихідний');
    break;
  case 'Monday':
  case 'Tuesday':
  case 'Wednesday':
  case 'Thursday':
  case 'Friday':
    console.log('Робочий день');
    break;
  default:
    console.log('Невідомо');
}

Область видимості в switch

Всі case-блоки розділяють один scope. Для ізоляції змінних — фігурні дужки в кожному case.

JavaScript
// ПРОБЛЕМА: спільний scope
switch (action) {
  case 'create':
    const msg = 'Creating'; // SyntaxError якщо 'update' теж оголошує msg
    break;
  case 'update':
    const msg = 'Updating'; // SyntaxError: already declared
    break;
}

// РІШЕННЯ: блоки для ізоляції
switch (action) {
  case 'create': {
    const msg = 'Creating';
    console.log(msg);
    break;
  }
  case 'update': {
    const msg = 'Updating'; // OK — окремий scope
    console.log(msg);
    break;
  }
}

Альтернатива: lookup object

JavaScript
// switch для простого маппінгу
function getStatusLabel(status) {
  switch (status) {
    case 'active':   return 'Активний';
    case 'inactive': return 'Неактивний';
    case 'banned':   return 'Заблокований';
    default:         return 'Невідомо';
  }
}

// Еквівалент через lookup object — коротший і розширюваний
const STATUS_LABELS = {
  active:   'Активний',
  inactive: 'Неактивний',
  banned:   'Заблокований',
};
const getStatusLabel2 = status => STATUS_LABELS[status] ?? 'Невідомо';

Підсумок

  • switch порівнює через ===. Типи мають збігатись.
  • Без break — fall-through. Навмисне fall-through для групування case.
  • Всі case в одному scope — ізолюйте блоками { } при оголошенні змінних.
  • Для простого маппінгу lookup object часто читабельніший.
