Оператор ?. (optional chaining, ES2020) дозволяє безпечно звертатись до вкладених властивостей об'єкта: якщо будь-яке посилання в ланцюгу є null або undefined — повертається undefined замість TypeError.

Проблема без ?.

JavaScript
const user = { profile: null };

// Без ?.: кожен крок потрібно перевіряти вручну
const street = user && user.profile && user.profile.address && user.profile.address.street;

// TypeError без перевірки
// const street2 = user.profile.address.street; // TypeError: Cannot read properties of null

Синтаксис

JavaScript
const user = {
  name: 'Олена',
  address: {
    city: 'Київ',
    street: null,
  },
  getAge: () => 28,
};

// ?. для властивості
console.log(user?.name);                    // "Олена"
console.log(user?.address?.city);           // "Київ"
console.log(user?.address?.street?.name);   // undefined — не TypeError

// ?. для методу
console.log(user?.getAge());                // 28
console.log(user?.getPhone?.());            // undefined — метод не існує

// ?.[] для динамічного ключа
const key = 'city';
console.log(user?.address?.[key]);          // "Київ"

// З відсутнім об'єктом
const guest = null;
console.log(guest?.name);     // undefined
console.log(guest?.greet?.()); // undefined

Комбінація з ??

JavaScript
// ?. + ?? — отримати значення або дефолт
const city    = user?.address?.city    ?? 'Невідомо';
const country = user?.address?.country ?? 'Україна';

// Замість громіздкого:
const cityOld = (user && user.address && user.address.city != null)
  ? user.address.city
  : 'Невідомо';

Обмеження і антипатерни

JavaScript
// НЕ можна використовувати зліва від присвоєння
// user?.name = 'Bob'; // SyntaxError

// ?. не замовчує логічні помилки — використовуйте обережно
// Якщо user завжди має бути об'єктом — відсутність user є помилкою
// ?. приховає її

// АНТИПАТЕРН: надмірне використання
const val = a?.b?.c?.d?.e?.f; // якщо кожен рівень є завжди — це маскує баги

// ПРАВИЛЬНО: ?. лише де null/undefined є очікуваним
const street = user?.address?.street; // address може бути відсутній — очікувано

Підсумок

  • obj?.prop → undefined якщо obj є null/undefined.
  • Три форми: ?.prop, ?.[key], ?.(args).
  • Зупиняє обчислення і повертає undefined при першому null/undefined в ланцюгу.
  • Комбінуйте з ?? для значень за замовчуванням.
  • Не використовуйте для присвоєння зліва. Не маскуйте реальні помилки надмірним ?..
