Коли об'єкт використовується в контексті де очікується примітив (арифметика, конкатенація, порівняння), рушій виконує внутрішню операцію ToPrimitive. Алгоритм визначається через hint — підказку про очікуваний тип.

Три hint-значення

HintКоли виникає
"string"Шаблонний літерал, alert(obj), ключ об'єкта
"number"Математичні оператори (-, *, /, порівняння), унарний +
"default"+ бінарний, == (без явного типу)

Алгоритм ToPrimitive

  1. Якщо є [Symbol.toPrimitive](hint) — викликає і повертає результат.
  2. Для hint "string": спочатку toString(), потім valueOf().
  3. Для hint "number" або "default": спочатку valueOf(), потім toString().

Symbol.toPrimitive — рекомендований спосіб

JavaScript
const money = {
  amount:   1500,
  currency: 'UAH',

  [Symbol.toPrimitive](hint) {
    switch (hint) {
      case 'number': return this.amount;
      case 'string': return `${this.amount} ${this.currency}`;
      default:       return this.amount; // default = number-like
    }
  }
};

console.log(+money);           // 1500        (number hint)
console.log(`${money}`);       // "1500 UAH"  (string hint)
console.log(money + 500);      // 2000        (default hint)
console.log(money > 1000);     // true        (number hint)

valueOf і toString

JavaScript
// Без Symbol.toPrimitive — рушій шукає valueOf і toString
const point = {
  x: 3,
  y: 4,

  valueOf() {
    // Викликається при number hint
    return Math.sqrt(this.x ** 2 + this.y ** 2); // відстань від 0
  },

  toString() {
    // Викликається при string hint
    return `(${this.x}, ${this.y})`;
  },
};

console.log(+point);        // 5     (valueOf)
console.log(`${point}`);    // "(3, 4)" (toString)
console.log(point * 2);     // 10    (valueOf)
console.log(point + '');    // "5"   (default → valueOf, потім String(5))

// Стандартний Object.prototype.valueOf() повертає сам об'єкт
// Стандартний Object.prototype.toString() повертає "[object Object]"
const plain = { value: 42 };
console.log(plain + 1);     // "[object Object]1" (toString → concat)

Date як приклад

JavaScript
const now = new Date();

// Date реалізує обидва методи
console.log(+now);    // Unix timestamp (ms) — valueOf
console.log(`${now}`); // "Thu Jan 01 2026..."  — toString

// Різниця дат — числовий контекст → valueOf
const d1 = new Date('2026-01-01');
const d2 = new Date('2026-06-01');
const diffMs = d2 - d1; // обидва перетворені через valueOf
console.log(diffMs / (1000 * 60 * 60 * 24)); // кількість днів

Підсумок

  • ToPrimitive виконується автоматично при використанні об'єкта в примітивному контексті.
  • Три hint: "string", "number", "default".
  • [Symbol.toPrimitive](hint) — найточніший спосіб контролювати перетворення.
  • Без Symbol.toPrimitive: для number-hint — valueOf() потім toString(); для string-hint — навпаки.
  • Стандартний valueOf() повертає сам об'єкт, тому більшість об'єктів конвертуються через toString() → "[object Object]".
