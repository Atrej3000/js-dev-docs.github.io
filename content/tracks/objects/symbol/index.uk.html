Symbol — примітивний тип що представляє гарантовано унікальний ідентифікатор. Навіть два символи з однаковим описом не рівні між собою. Символи використовуються як ключі властивостей для запобігання конфліктів імен.

Створення і унікальність

JavaScript
// Symbol() — завжди унікальний
const id1 = Symbol('id');
const id2 = Symbol('id');

console.log(id1 === id2);  // false — різні символи незважаючи на однаковий опис
console.log(typeof id1);   // "symbol"

// Опис (description) — лише для налагодження
console.log(id1.description);   // "id"
console.log(id1.toString());    // "Symbol(id)"

// Symbol не конвертується в рядок автоматично
// console.log(`id: ${id1}`); // TypeError
console.log(`id: ${id1.toString()}`); // OK
console.log(`id: ${String(id1)}`);    // OK

Symbol як ключі об'єкта

JavaScript
const USER_ID = Symbol('userId');
const ROLE    = Symbol('role');

const user = {
  name: 'Олена',
  [USER_ID]: 42,      // Symbol-ключ
  [ROLE]: 'admin',
};

console.log(user[USER_ID]); // 42
console.log(user[ROLE]);    // "admin"

// Symbol-ключі невидимі для стандартних ітерацій
console.log(Object.keys(user));   // ['name'] — без символів
console.log(JSON.stringify(user)); // '{"name":"Олена"}' — символи пропущені

// Але доступні через спеціальний метод
console.log(Object.getOwnPropertySymbols(user)); // [Symbol(userId), Symbol(role)]

// Reflect.ownKeys — повертає всі ключи включно з символами
console.log(Reflect.ownKeys(user)); // ['name', Symbol(userId), Symbol(role)]

Symbol.for — глобальний реєстр

JavaScript
// Symbol.for шукає в глобальному реєстрі або створює
const s1 = Symbol.for('shared.key');
const s2 = Symbol.for('shared.key');

console.log(s1 === s2); // true — однаковий символ з реєстру

// Symbol.keyFor — отримати опис зареєстрованого символу
console.log(Symbol.keyFor(s1));        // "shared.key"
console.log(Symbol.keyFor(Symbol())); // undefined — локальний символ не в реєстрі

Well-known Symbols

ECMAScript визначає вбудовані символи (well-known symbols), що керують поведінкою об'єктів. Вони доступні як статичні властивості Symbol.

JavaScript
// Symbol.iterator — робить об'єкт iterable
const range = {
  from: 1,
  to: 5,
  [Symbol.iterator]() {
    let current = this.from;
    const last  = this.to;
    return {
      next() {
        return current <= last
          ? { value: current++, done: false }
          : { value: undefined, done: true };
      }
    };
  }
};

for (const num of range) {
  console.log(num); // 1, 2, 3, 4, 5
}

// Symbol.toPrimitive — перетворення в примітив
const temperature = {
  value: 22,
  [Symbol.toPrimitive](hint) {
    if (hint === 'number') return this.value;
    if (hint === 'string') return `${this.value}°C`;
    return this.value;
  }
};

console.log(+temperature);         // 22
console.log(`${temperature}`);     // "22°C"

// Symbol.hasInstance — поведінка instanceof
// Symbol.species — конструктор для похідних об'єктів
// Symbol.asyncIterator — асинхронна ітерація

Підсумок

  • Symbol() — завжди унікальний. Два символи з однаковим описом не рівні.
  • Symbol-ключі не видимі для Object.keys, for...in, JSON.stringify.
  • Object.getOwnPropertySymbols / Reflect.ownKeys — для доступу до Symbol-ключів.
  • Symbol.for — глобальний реєстр: одне ім'я = один символ.
  • Well-known symbols (Symbol.iterator, Symbol.toPrimitive тощо) керують вбудованою поведінкою.
