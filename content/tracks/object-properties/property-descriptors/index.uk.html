Кожна властивість об'єкта має внутрішні прапори (дескрипторний запис), що визначають її поведінку. За замовчуванням властивості, створені через літерал або присвоєння, мають всі прапори true.

Три прапори властивості

  • writable — значення можна змінити.
  • enumerable — властивість потрапляє в for...in і Object.keys.
  • configurable — дескриптор можна змінити, властивість можна видалити.
JavaScript
const user = { name: 'Alice' };

// Отримати дескриптор
console.log(Object.getOwnPropertyDescriptor(user, 'name'));
// { value: 'Alice', writable: true, enumerable: true, configurable: true }

// Всі дескриптори
console.log(Object.getOwnPropertyDescriptors(user));

Object.defineProperty

JavaScript
const config = {};

Object.defineProperty(config, 'version', {
  value:        '2.0',
  writable:     false,    // не можна перезаписати
  enumerable:   true,
  configurable: false,    // не можна видалити чи перенастроїти
});

console.log(config.version);  // "2.0"
config.version = '3.0';       // мовчки ігнорується (TypeError у strict)
console.log(config.version);  // "2.0"

// Не-enumerable: не потрапляє в for...in і Object.keys
Object.defineProperty(config, '_internal', {
  value: 42,
  enumerable: false,
  writable: true,
  configurable: true,
});
console.log(Object.keys(config));    // ['version'] — _internal прихований
console.log(config._internal);       // 42 — доступ прямий є

// defineProperties: кілька одночасно
Object.defineProperties(config, {
  host: { value: 'localhost', writable: false, enumerable: true, configurable: false },
  port: { value: 3000,        writable: false, enumerable: true, configurable: false },
});

Запечатування і заморожування

JavaScript
const obj = { x: 1, y: 2 };

// Object.seal: configurable=false для всіх, додавання/видалення заборонено
// але writable залишається true
Object.seal(obj);
obj.x = 10;         // OK — значення можна змінити
obj.z = 3;          // ігнорується — нові властивості заборонені
delete obj.x;       // ігнорується — видалення заборонено
console.log(Object.isSealed(obj)); // true

// Object.freeze: writable=false + seal
const frozen = Object.freeze({ a: 1, b: 2 });
frozen.a = 99;      // ігнорується (TypeError у strict)
frozen.c = 3;       // ігнорується
console.log(frozen.a); // 1
console.log(Object.isFrozen(frozen)); // true

// Заморожування ПОВЕРХНЕВЕ
const deep = Object.freeze({ inner: { val: 1 } });
deep.inner.val = 99; // OK — inner не заморожений!
console.log(deep.inner.val); // 99

Підсумок

  • Три прапори: writable, enumerable, configurable.
  • Object.defineProperty — точне налаштування. Відсутні прапори = false при створенні через defineProperty.
  • Object.seal — забороняє додавання/видалення. Object.freeze = seal + writable:false.
  • Заморожування поверхневе — вкладені об'єкти не заморожуються.
