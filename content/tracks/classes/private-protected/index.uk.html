Інкапсуляція — приховання внутрішньої реалізації. JavaScript надає два рівні: приватні (#field) — мовна гарантія, захищені — конвенція через підкреслення (_field). Приватні поля доступні лише всередині тіла класу де вони визначені.

Приватні поля і методи (#)

JavaScript
class BankAccount {
  #balance;      // приватне поле
  #owner;

  constructor(owner, initialBalance = 0) {
    this.#owner   = owner;
    this.#balance = initialBalance;
  }

  // Приватний метод
  #validate(amount) {
    if (amount <= 0) throw new RangeError('Amount must be positive');
    return true;
  }

  deposit(amount) {
    this.#validate(amount);
    this.#balance += amount;
  }

  withdraw(amount) {
    this.#validate(amount);
    if (amount > this.#balance) throw new Error('Insufficient funds');
    this.#balance -= amount;
  }

  get balance()  { return this.#balance; }
  get owner()    { return this.#owner; }
}

const acc = new BankAccount('Alice', 1000);
acc.deposit(500);
console.log(acc.balance); // 1500
// acc.#balance;           // SyntaxError — приватне!

Захищені властивості (конвенція _)

JavaScript
// _ означає "не чіпати ззовні" — угода між розробниками, не мовна гарантія
class Logger {
  _prefix = '[LOG]';   // захищене — можна перевизначити в нащадку
  #output  = console;  // приватне — лише Logger

  log(message) {
    this.#output.log(`${this._prefix} ${message}`);
  }
}

class DebugLogger extends Logger {
  _prefix = '[DEBUG]';  // нащадок може перевизначити захищену властивість
}

const d = new DebugLogger();
d.log('test'); // "[DEBUG] test"

Перевірка приватного поля через in

JavaScript
class Point {
  #x; #y;
  constructor(x, y) { this.#x = x; this.#y = y; }

  // Перевірка що об'єкт є Point (не instanceof — уникає cross-realm проблем)
  static isPoint(obj) {
    return #x in obj; // true якщо obj має приватне поле #x
  }
}

console.log(Point.isPoint(new Point(1,2))); // true
console.log(Point.isPoint({}));              // false

Підсумок

  • Приватні поля #field: мовна гарантія. Синтаксична помилка при доступі ззовні.
  • Захищені (_field): лише конвенція. Технічно доступні всім.
  • #field in obj — безпечна перевірка наявності приватного поля.
  • Приватні поля НЕ успадковуються нащадками.
