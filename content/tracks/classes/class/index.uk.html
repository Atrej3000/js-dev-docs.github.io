Клас (ES6) — синтаксичний цукор поверх прotototype-успадкування. Надає зручний синтаксис для створення конструкторів і методів, автоматично встановлює прotototype і захищає від виклику без new.

Базовий синтаксис

JavaScript
class User {
  // Конструктор: викликається при new User(...)
  constructor(name, email) {
    this.name  = name;
    this.email = email;
  }

  // Метод: зберігається у User.prototype
  greet() {
    return `Привіт, ${this.name}!`;
  }

  describe() {
    return `${this.name} (${this.email})`;
  }
}

const alice = new User('Alice', 'alice@example.com');
console.log(alice.greet());    // "Привіт, Alice!"
console.log(alice.describe()); // "Alice (alice@example.com)"

// Методи класу — не enumerable (відмінність від ручного prototype)
console.log(Object.keys(alice)); // [] — методи не перелічуються

// Без new — TypeError (на відміну від функцій-конструкторів)
// User('Bob', 'b@b.com'); // TypeError: Class constructor must be called with new

Поля класу (Class Fields)

JavaScript
class Counter {
  // Публічне поле — власна властивість екземпляра (не prototype)
  count = 0;
  step  = 1;

  // Приватне поле — доступне лише всередині класу
  #history = [];

  increment() {
    this.count += this.step;
    this.#history.push(this.count);
  }

  getHistory() { return [...this.#history]; }
}

const c = new Counter();
c.increment();
c.increment();
console.log(c.count);        // 2
console.log(c.getHistory()); // [1, 2]
// c.#history;               // SyntaxError — приватне

Статичні методи і поля

JavaScript
class MathHelper {
  static PI = 3.14159265;

  static circleArea(r) { return MathHelper.PI * r ** 2; }
  static distance(p1, p2) {
    return Math.sqrt((p2.x - p1.x) ** 2 + (p2.y - p1.y) ** 2);
  }
}

// Виклик через клас, не через екземпляр
console.log(MathHelper.PI);              // 3.14159265
console.log(MathHelper.circleArea(5));   // ~78.54

// Фабричний метод
class User {
  #name; #email;
  constructor(name, email) { this.#name = name; this.#email = email; }

  static fromJSON(json) {
    const { name, email } = JSON.parse(json);
    return new User(name, email);
  }
}

const u = User.fromJSON('{"name":"Bob","email":"b@b.com"}');

Підсумок

  • Клас: constructor — ініціалізація; методи — на prototype; поля класу — власна властивість екземпляра.
  • Методи класу не enumerable. Виклик без new → TypeError.
  • Приватні поля #field — недоступні ззовні, навіть через рефлексію.
  • Статичні методи і поля — на самому класі, не на екземплярах.
