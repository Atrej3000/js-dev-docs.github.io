Вбудовані класи (Array, Map, Error тощо) можна розширювати через extends. Однак є нюанс: Symbol.species контролює, який конструктор використовується у вбудованих методах, що повертають новий екземпляр.

Розширення Array

JavaScript
class PowerArray extends Array {
  isEmpty() { return this.length === 0; }

  sum() { return this.reduce((acc, val) => acc + val, 0); }

  average() { return this.length ? this.sum() / this.length : 0; }
}

const arr = new PowerArray(1, 2, 3, 4, 5);
console.log(arr.isEmpty()); // false
console.log(arr.sum());     // 15
console.log(arr.average()); // 3

// Метод filter повертає PowerArray, не Array!
const evens = arr.filter(n => n % 2 === 0);
console.log(evens instanceof PowerArray); // true
console.log(evens.sum());                 // 6

Symbol.species

JavaScript
// Вбудовані методи map, filter, slice використовують Symbol.species
// для визначення конструктора нового об'єкта

class PowerArray extends Array {
  // Примусово повертати звичайний Array з map/filter
  static get [Symbol.species]() { return Array; }

  sum() { return this.reduce((a, b) => a + b, 0); }
}

const pa = new PowerArray(1, 2, 3);
const mapped = pa.map(x => x * 2);

console.log(mapped instanceof PowerArray); // false — звичайний Array
console.log(mapped instanceof Array);      // true
// console.log(mapped.sum()); // TypeError — sum немає в Array

Розширення Error

JavaScript
class ValidationError extends Error {
  constructor(message, field) {
    super(message);
    this.name  = 'ValidationError';
    this.field = field;
  }
}

class HttpError extends Error {
  constructor(statusCode, message) {
    super(message);
    this.name       = 'HttpError';
    this.statusCode = statusCode;
  }
}

try {
  throw new ValidationError('Required field', 'email');
} catch (e) {
  if (e instanceof ValidationError) {
    console.log(e.field);   // 'email'
    console.log(e.message); // 'Required field'
    console.log(e.name);    // 'ValidationError'
    console.log(e.stack);   // стек виклику
  }
}

Розширення Map

JavaScript
class TypedMap extends Map {
  constructor(keyType, valueType) {
    super();
    this.keyType   = keyType;
    this.valueType = valueType;
  }

  set(key, value) {
    if (typeof key !== this.keyType) {
      throw new TypeError(\`Key must be \${this.keyType}\`);
    }
    if (typeof value !== this.valueType) {
      throw new TypeError(\`Value must be \${this.valueType}\`);
    }
    return super.set(key, value);
  }
}

const map = new TypedMap('string', 'number');
map.set('age', 30);        // OK
// map.set(42, 30);        // TypeError: Key must be string
// map.set('age', 'old');  // TypeError: Value must be number

Не всі вбудовані методи дотримуються Symbol.species. Наприклад, flat(), flatMap() в деяких рушіях не поважають species. Тестуй поведінку конкретного середовища.

Підсумок

  • Вбудовані класи розширюються стандартним extends
  • Методи, що повертають новий об'єкт (map, filter), використовують Symbol.species
  • Перевизнач static get [Symbol.species]() { return Array; } щоб повертати базовий клас
  • Найпоширеніші кейси: кастомні Error, збагачені Array, типізовані Map
