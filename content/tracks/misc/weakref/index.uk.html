WeakRef та FinalizationRegistry — просунуті інструменти для роботи з пам'яттю. Вони дозволяють тримати слабке посилання на об'єкт, не заважаючи збирачу сміття його видалити.

Обережно

Ці можливості рідко потрібні у звичайному коді. Використовуй їх тільки якщо точно розумієш навіщо.

WeakRef

WeakRef зберігає слабке посилання на об'єкт — збирач сміття може видалити його в будь-який момент, якщо немає інших сильних посилань.

let user = { name: 'Alice' };

// Створюємо слабке посилання
const weakUser = new WeakRef(user);

// Отримати об'єкт (може повернути undefined, якщо вже зібраний)
const ref = weakUser.deref();
if (ref) {
  console.log(ref.name); // 'Alice'
} else {
  console.log('Object was garbage collected');
}

// Прибираємо сильне посилання
user = null;
// Тепер збирач сміття може видалити об'єкт
// weakUser.deref() може повернути undefined

FinalizationRegistry

Дозволяє зареєструвати колбек, який викличеться коли об'єкт буде видалено збирачем сміття.

const registry = new FinalizationRegistry((value) => {
  console.log('Cleaned up:', value);
});

let user = { name: 'Bob' };

// Реєструємо об'єкт з токеном
registry.register(user, 'user-bob');

// Прибираємо посилання
user = null;

// Колись після збирання сміття:
// 'Cleaned up: user-bob'

Практичне застосування

Найчастіше WeakRef використовується для кешування без витоків пам'яті:

class Cache {
  #cache = new Map();
  #registry = new FinalizationRegistry((key) => {
    this.#cache.delete(key); // очищаємо запис коли об'єкт видалено
  });

  set(key, value) {
    this.#cache.set(key, new WeakRef(value));
    this.#registry.register(value, key);
  }

  get(key) {
    const ref = this.#cache.get(key);
    return ref ? ref.deref() : undefined;
  }
}

const cache = new Cache();
let bigData = { size: '100MB', content: '...' };
cache.set('data', bigData);

console.log(cache.get('data')); // { size: '100MB', ... }
bigData = null; // може бути видалено збирачем сміття

Підсумок

  • new WeakRef(obj) — слабке посилання на об'єкт
  • ref.deref() — отримати об'єкт або undefined якщо вже видалено
  • new FinalizationRegistry(callback) — реєстрація колбека на видалення
  • registry.register(obj, token) — реєструє об'єкт для відстеження
  • Момент виклику колбека не гарантований — залежить від збирача сміття
  • Не використовуй для критичної логіки — тільки для оптимізацій
