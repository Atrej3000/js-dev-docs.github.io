A code editor is one of a developer's main tools. A well-configured editor reduces routine work, helps catch mistakes earlier, and makes large codebases easier to navigate.

## Why this matters

Editor choice directly affects productivity. Features such as autocompletion, inline diagnostics, quick navigation, and built-in debugging reduce the time between writing code and finding mistakes.

## Visual Studio Code

Visual Studio Code is the default starting point for many JavaScript and TypeScript developers. It is free, has a large extension ecosystem, and has strong TypeScript support out of the box.

Useful capabilities:

- IntelliSense for autocompletion and inline hints
- go-to-definition and rename refactoring
- built-in debugging for browser and Node.js projects
- integrated Git tools
- a terminal inside the editor

### Recommended extensions for JS/TS

| Extension | Purpose |
| --- | --- |
| `ESLint` | static analysis and rule enforcement |
| `Prettier` | automatic formatting |
| `Error Lens` | inline display of errors and warnings |
| `GitLens` | richer Git history and blame information |
| `Path Intellisense` | file path autocompletion |
| `Import Cost` | package size hints for imports |

## WebStorm

WebStorm is a full-featured IDE from JetBrains. It is paid software, but many students and open-source contributors can use it under special licenses.

It is especially useful when:

- your TypeScript codebase is large and complex
- you want advanced refactorings
- you prefer an all-in-one IDE with strong built-in analysis

## Lightweight editors

For quick edits or terminal-centric workflows, lighter tools can also work well:

- **Neovim** with LSP support
- **Zed**
- other editors that can connect to TypeScript's language server

These are good choices when you already know what you want from your setup and do not mind configuring it.

## Essential features for any JavaScript editor

No matter which editor you choose, a productive JavaScript setup should include:

- **Language Server Protocol support** for navigation, completions, and diagnostics
- syntax highlighting for JavaScript, TypeScript, JSON, Markdown, JSX, and TSX
- integration with ESLint and Prettier
- an integrated terminal

## Summary

- VS Code is the most practical default choice for JavaScript and TypeScript.
- WebStorm is a strong option for larger or more complex projects.
- Lightweight editors can be excellent when properly configured.
- The most important features are LSP support, linting, formatting, and fast navigation.
