Браузерні інструменти розробника (DevTools) — вбудований набір утиліт для налагодження, профілювання і аналізу веб-сторінок. Для JavaScript-розробника ключові панелі: Console, Sources і Network.

Чому це важливо

DevTools — перше місце, куди розробник звертається при виникненні помилки. Швидкість налагодження напряму залежить від уміння ефективно використовувати консоль, точки зупинки і перегляд стану виконання. Ці навички скорочують час виправлення типових помилок з годин до хвилин.

Як відкрити DevTools

ПлатформаСкорочення
Windows / LinuxF12 або Ctrl+Shift+I
macOSCmd+Option+I
Будь-яка ОСПравий клік → «Inspect» / «Переглянути код»

Ці інструкції стосуються Chrome і Edge (Chromium-based). Firefox та Safari мають аналогічні DevTools з незначними відмінностями в інтерфейсі.

Панель Console

Console — REPL-середовище (Read-Eval-Print Loop) для виконання довільного JS у контексті поточної сторінки. Тут відображаються повідомлення з коду і помилки виконання.

Методи console

JavaScript
// Виведення значень
console.log('звичайне повідомлення');
console.info('інформаційне');
console.warn('попередження');  // жовтий фон
console.error('помилка');      // червоний фон

// Структуровані дані
const user = { id: 1, name: 'admin', roles: ['read', 'write'] };
console.log(user);        // інтерактивне дерево об'єкта
console.table([user]);    // табличне представлення

// Групування
console.group('Auth flow');
console.log('checking token...');
console.log('token valid');
console.groupEnd();

// Вимірювання часу
console.time('fetch');
await fetch('/api/data');
console.timeEnd('fetch'); // "fetch: 42ms"

// Умовний вивід
console.assert(user.id > 0, 'user.id must be positive', user);
// виводить повідомлення лише якщо перша умова false
console.log у продакшені

Видаляйте або умовно відключайте console.log у продакшені. Виведення у консоль має вартість продуктивності і може розкривати чутливі дані. Використовуйте спеціалізовані логери (winston, pino) або прапорці рівнів логування.

Панель Sources: дебаґер

Sources — повноцінний JavaScript-дебаґер. Дозволяє зупиняти виконання коду у будь-якому місці і досліджувати стан програми.

Точки зупинки (Breakpoints)

Клік на номер рядка у вихідному коді встановлює точку зупинки. При досягненні цього рядка виконання призупиняється і стають доступні:

  • Scope — всі змінні поточного та зовнішніх scope
  • Call Stack — стек викликів від точки зупинки до верхнього рівня
  • Watch — довільні вирази, що обчислюються в поточному контексті

Крокове виконання

ДіяКлавішаЗначення
ResumeF8Продовжити до наступної точки зупинки
Step overF10Наступний рядок, не заходячи у функцію
Step intoF11Зайти всередину функції
Step outShift+F11Вийти з поточної функції

Оператор debugger

Оператор debugger у коді діє як точка зупинки — але лише якщо DevTools відкриті. Якщо DevTools закриті, оператор ігнорується.

JavaScript
function processPayment(amount, currency) {
  debugger; // виконання зупиниться тут (якщо DevTools відкриті)

  if (amount <= 0) throw new RangeError('Amount must be positive');
  return convert(amount, currency);
}

// Видаліть debugger перед комітом —
// він не впливає на продакшен, але є ознакою незавершеної роботи

Умовні точки зупинки

Правий клік на точку зупинки → «Edit breakpoint» дозволяє задати умову: виконання зупиниться лише якщо вираз повертає true.

JavaScript
// Умова для точки зупинки в цьому рядку:
// user.role === 'admin' && requestCount > 100
// Зупиниться лише при адміністраторі з великою кількістю запитів
for (const user of users) {
  processUser(user); // ← точка зупинки з умовою
}

Панель Network

Network відображає всі мережеві запити сторінки: XHR, Fetch, завантаження скриптів, стилів, зображень.

Для кожного запиту доступні:

  • Headers — заголовки запиту і відповіді
  • Payload — тіло запиту (для POST/PUT)
  • Response — відповідь сервера
  • Timing — детальний розбір часу: DNS, TCP, TTFB, завантаження
Зберігати логи між перезавантаженнями

За замовчуванням Network очищається при перезавантаженні сторінки. Увімкніть опцію Preserve log (Preserve log ✓), щоб зберігати запити між перезавантаженнями — зручно при налагодженні POST-форм та редиректів.

Панель Elements

Elements дозволяє переглядати і редагувати DOM та CSS у реальному часі. Зміни в Elements не зберігаються після перезавантаження — це середовище для швидких експериментів.

Корисна функція: правий клік на елемент у Elements → «Break on» дозволяє встановити точку зупинки на зміну DOM-елемента, зміну атрибута або видалення вузла.

Підсумок

  • DevTools відкривається через F12 або Ctrl+Shift+I / Cmd+Option+I.
  • Console — REPL для виконання JS і виведення діагностики. console.table, console.group, console.time — корисні розширення.
  • Sources — дебаґер з точками зупинки, крокове виконання (F10/F11), перегляд Scope і Call Stack.
  • Оператор debugger у коді — програмна точка зупинки. Видаляйте перед комітом.
  • Умовні точки зупинки — для налагодження циклів і рідкісних умов без зупинки на кожній ітерації.
  • Network — аналіз мережевих запитів: статус, заголовки, тіло, таймінги.
