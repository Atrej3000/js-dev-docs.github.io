Динамічний import() — функція, що повертає Promise і дозволяє завантажувати модулі в runtime. Це основа code splitting: вантажити код лише тоді, коли він реально потрібен.

Синтаксис

JavaScript
// Статичний import — завжди на верхньому рівні
import { add } from './math.js';

// Динамічний import() — де завгодно, повертає Promise
const module = await import('./math.js');
module.add(1, 2); // 3
module.default;   // default export

// Деструктуризація
const { add, PI } = await import('./math.js');

// Без await — через .then
import('./heavy-module.js')
  .then(module => module.init())
  .catch(err => console.error('Не вдалось завантажити:', err));

Умовне завантаження

JavaScript
// Завантажувати лише у певних умовах
async function loadPolyfill() {
  if (!window.IntersectionObserver) {
    await import('./polyfills/intersection-observer.js');
  }
}

// Завантаження по події
button.addEventListener('click', async () => {
  const { openModal } = await import('./modal.js');
  openModal();
});

// Завантаження на основі даних (перемикач локалі)
async function loadLocale(lang) {
  const { messages } = await import(`./locales/${lang}.js`);
  return messages;
}
const ua = await loadLocale('uk'); // ./locales/uk.js

Шаблонні рядки в import() підтримуються, але bundler'и (Vite, Webpack) вимагають хоча б статичного префікса (./locales/) для правильного аналізу залежностей під час збірки.

Підсумок

  • import(path) → Promise з об'єктом модуля
  • Основне застосування: code splitting, умовне завантаження, lazy routes
  • У React: React.lazy() + Suspense
  • Шаблонний шлях підтримується, але потребує статичного префікса для bundler
