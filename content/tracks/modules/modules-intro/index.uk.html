Модулі — файли з власним scope: змінні та функції не потрапляють у глобальний простір автоматично. ESM (ECMAScript Modules) — стандарт: import / export. Це вирішує проблеми конфліктів імен, залежностей і організації коду.

Що дає модуль

JavaScript
// without modules — все у глобальному просторі
var user = 'Alice';    // window.user у браузері
var user = 'Bob';      // перезаписує! конфлікт

// З модулями (type="module" або .mjs)
// Кожен файл — окремий scope
// user у цьому файлі не видний зовні без export

export

JavaScript
// Named exports — кілька з одного файлу
export const PI = 3.14159;
export function add(a, b) { return a + b; }
export class Vector { constructor(x, y) { this.x = x; this.y = y; } }

// Export в кінці файлу
const secret = 42;
const helper = x => x * 2;
export { secret, helper };

// Перейменування при export
export { secret as token, helper as double };

// Default export — один на файл
export default class User {
  constructor(name) { this.name = name; }
}

import

JavaScript
// Named import
import { PI, add } from './math.js';
console.log(PI);      // 3.14159
console.log(add(1,2)); // 3

// Перейменування при import
import { add as sum } from './math.js';

// Namespace import — всі named exports як об'єкт
import * as Math from './math.js';
Math.add(1, 2);

// Default import — будь-яке ім'я
import User from './user.js';
import MyUser from './user.js'; // теж валідно

// Default + named разом
import User, { PI, add } from './module.js';

Модулі у браузері

HTML

Модулі у браузері завжди defer — виконуються після повного завантаження HTML. CORS: файл повинен завантажуватись з сервера (не file://) — локальний open index.html не працює без localhost.

Особливості ESM

JavaScript
// 1. Строгий режим автоматично
// 'use strict'; — не потрібно, вже є

// 2. Код модуля виконується ОДИН раз (при першому import)
// Повторні import того самого модуля — кешований результат
import './init.js'; // init.js виконається один раз
import './init.js'; // повторно — не виконується

// 3. import hoisting — переміщується на початок файлу
// (але це статичний аналіз, не eval-time)
console.log('before import');
import { x } from './x.js'; // все одно виконається першим
console.log('after import');

// 4. import.meta — мета-інформація поточного модуля
console.log(import.meta.url);  // URL файлу
console.log(import.meta.env);  // у Vite/bundler

Підсумок

  • Модуль = файл з власним scope + строгий режим автоматично
  • export: named (кілька) та default (один)
  • import: named, namespace (* as), default
  • У браузері: <script type="module"> + потрібен HTTP-сервер
  • Код модуля виконується один раз — результат кешується
