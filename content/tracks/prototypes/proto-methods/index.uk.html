Сучасні методи роботи з прототипами: Object.create(), Object.getPrototypeOf(), Object.setPrototypeOf(), Object.getOwnPropertyNames(). Вони замінюють застарілий і проблемний __proto__.

Object.create()

JavaScript
// Створення об'єкта з явним прототипом
const animal = {
  speak() { return `${this.name} says ${this.sound}`; }
};

const dog = Object.create(animal);
dog.name  = 'Rex';
dog.sound = 'Woof';
console.log(dog.speak()); // 'Rex says Woof'
console.log(Object.getPrototypeOf(dog) === animal); // true

// Клонування об'єкта зі збереженням прототипу
const clone = Object.create(
  Object.getPrototypeOf(dog),
  Object.getOwnPropertyDescriptors(dog)
);

// Об'єкт без прототипу (чистий словник)
const dict = Object.create(null);
dict.key = 'value';
// Немає toString, hasOwnProperty — ідеальний Map для примітивних ключів

getPrototypeOf / setPrototypeOf

JavaScript
class Animal { speak() {} }
class Dog extends Animal {}

const dog = new Dog();
Object.getPrototypeOf(dog) === Dog.prototype;           // true
Object.getPrototypeOf(Dog.prototype) === Animal.prototype; // true

// setPrototypeOf — змінює прототип після створення
const obj = { greet() { return 'hello'; } };
const extension = { farewell() { return 'bye'; } };

Object.setPrototypeOf(extension, obj);
console.log(extension.greet()); // 'hello' — успадковано

Object.setPrototypeOf() після створення об'єкта — повільна операція. Рушій не може оптимізувати «приховані класи» об'єкта. Завжди краще задати прототип під час створення через Object.create().

Власні властивості vs успадковані

JavaScript
function Animal(name) { this.name = name; }
Animal.prototype.speak = function() { return this.name; };

const cat = new Animal('Whiskers');

// Власні властивості
Object.keys(cat);                           // ['name']
Object.getOwnPropertyNames(cat);            // ['name']
cat.hasOwnProperty('name');                 // true
cat.hasOwnProperty('speak');                // false

// Всі перелічувані (включаючи прототип)
for (const k in cat) console.log(k);       // 'name', 'speak'

// Рекомендований паттерн: перевірка власних
for (const k in cat) {
  if (Object.hasOwn(cat, k)) console.log(k); // тільки 'name'
}
// Object.hasOwn — ES2022, краще ніж cat.hasOwnProperty(k)

Дескриптори та копіювання

JavaScript
const source = { get name() { return 'Alice'; } };

// Звичайний assign НЕ копіює getter — викличе і скопіює значення
const bad  = Object.assign({}, source);
// bad.name — звичайна властивість 'Alice', не getter

// Правильне глибоке копіювання зі збереженням дескрипторів
const good = Object.create(
  Object.getPrototypeOf(source),
  Object.getOwnPropertyDescriptors(source)
);
// good.name — залишається getter

Підсумок

  • Object.create(proto) — явне задання прототипу при створенні
  • Object.getPrototypeOf(obj) — читання прототипу (замість __proto__)
  • Object.setPrototypeOf(obj, proto) — зміна після створення (повільно!)
  • Object.create(null) — чистий словник без Object-методів
  • Object.hasOwn(obj, key) (ES2022) — безпечна перевірка власних властивостей
