Сучасний JavaScript (ES2020+) не підтримується в старих браузерах. Два інструменти вирішують цю проблему: транспілери — перетворюють синтаксис, поліфіли — реалізують відсутні API.

Транспілер: перетворення синтаксису

Транспілер читає вихідний код і перетворює синтаксис ES2020+ на еквівалентний ES5/ES2015. Це синтаксичне перетворення — нові конструкції мови.

JavaScript — вхід (ES2022)
// Стрілкові функції, деструктуризація, optional chaining
const getUserName = (user) => user?.profile?.name ?? 'Guest';

class Counter {
  #count = 0;           // приватне поле класу
  increment() { this.#count++; }
  get value() { return this.#count; }
}
JavaScript — вихід Babel (ES5)
// Babel трансформує у сумісний з ES5 код
var getUserName = function(user) {
  var _user, _user$profile;
  return (_user = user) === null || _user === void 0
    ? void 0
    : (_user$profile = _user.profile) === null
    ? void 0
    : _user$profile.name !== null && _user$profile.name !== void 0
    ? _user$profile.name
    : 'Guest';
};
// Приватні поля → WeakMap (спрощено)

Babel

Найпоширеніший JavaScript-транспілер. Перетворює новий синтаксис і JSX. Конфігурується через .babelrc або babel.config.json.

JSON — babel.config.json
{
  "presets": [
    ["@babel/preset-env", {
      "targets": "> 0.5%, last 2 versions, not dead",
      "useBuiltIns": "usage",
      "corejs": 3
    }]
  ]
}

@babel/preset-env автоматично визначає які трансформації потрібні для цільових браузерів. useBuiltIns: "usage" вставляє лише необхідні поліфіли.

Поліфіл: реалізація відсутнього API

Поліфіл — код, що реалізує API яке браузер ще не підтримує. На відміну від транспілера — це не перетворення синтаксису, а додавання нових функцій.

JavaScript
// Поліфіл для Array.prototype.at (ES2022) — ручна реалізація
if (!Array.prototype.at) {
  Array.prototype.at = function(index) {
    const i = Math.trunc(index) || 0;
    if (i < 0) return this[this.length + i];
    return this[i];
  };
}

// Поліфіл для Promise (якщо відсутній)
// Замість ручного написання — використовуйте core-js

// Перевірка підтримки перед використанням нового API
if (typeof globalThis.structuredClone === 'function') {
  const copy = structuredClone(data);
} else {
  const copy = JSON.parse(JSON.stringify(data)); // fallback
}

core-js

core-js — найповніша бібліотека поліфілів для стандартних об'єктів JavaScript (Array, Promise, Map, Set, Symbol тощо). Разом з Babel вона покриває більшість потреб.

JavaScript
// Ручне підключення (рідко потрібно з Babel useBuiltIns: "usage")
import 'core-js/stable';          // всі стабільні поліфіли
import 'core-js/actual/array/at'; // тільки конкретний

// Або вибірково
import 'core-js/actual/promise';
import 'core-js/actual/set';

browserslist

Файл .browserslistrc (або поле browserslist в package.json) визначає цільові браузери. Babel, PostCSS, Autoprefixer читають цей файл для визначення необхідних трансформацій.

text — .browserslistrc
# Більше 0.5% частки ринку, останні 2 версії, живі браузери
> 0.5%
last 2 versions
not dead
not IE 11

# Для сучасних проектів (менше поліфілів)
# last 1 Chrome version
# last 1 Firefox version
# last 2 Safari major versions

TypeScript як транспілер

TypeScript через tsc або ts-loader/esbuild також виконує транспіляцію: компілює TypeScript у JavaScript з заданою версією target у tsconfig.json.

JSON — tsconfig.json (фрагмент)
{
  "compilerOptions": {
    "target": "ES2017",   // генерований JS сумісний з ES2017
    "lib": ["ES2024", "DOM"],
    "useDefineForClassFields": true
  }
}

Сучасна альтернатива

Для проектів що підтримують тільки сучасні браузери (Chrome 90+, Firefox 90+, Safari 14+) поліфіли і транспіляція часто не потрібні — всі необхідні API підтримуються нативно. Перевіряйте caniuse.com для конкретного API.

Підсумок

  • Транспілер (Babel, tsc) — перетворює новий синтаксис у старіший. Вирішує: ?.`, ??, стрілкові функції, приватні поля класів.
  • Поліфіл (core-js) — реалізує відсутні API. Вирішує: Promise, Array.at, Map, structuredClone.
  • @babel/preset-env + useBuiltIns: "usage" автоматизують вибір трансформацій і поліфілів.
  • browserslist визначає цільові браузери для всіх інструментів.
  • Для сучасних браузерів — поліфіли часто не потрібні.
