Масив — впорядкована колекція значень з числовою індексацією. Масиви є об'єктами зі спеціальною числовою індексацією та властивістю length. Вони динамічні: можна додавати та видаляти елементи в будь-який момент.

Створення масиву

JavaScript
// Літерал (рекомендований)
const fruits  = ['apple', 'banana', 'cherry'];
const mixed   = [1, 'two', true, null, { x: 3 }];
const empty   = [];

// Array.from — з iterable або array-like
Array.from('abc');           // ['a', 'b', 'c']
Array.from({ length: 3 }, (_, i) => i * 2); // [0, 2, 4]
Array.from(new Set([1, 2, 2, 3])); // [1, 2, 3]

// Array.of — з аргументів
Array.of(1, 2, 3);   // [1, 2, 3]

// Конструктор (не рекомендовано — неоднозначний)
new Array(3);        // [empty × 3] — масив з 3 порожніми слотами!

Доступ і модифікація

JavaScript
const arr = ['a', 'b', 'c', 'd'];

console.log(arr[0]);      // "a"
console.log(arr.at(-1));  // "d" — ES2022
console.log(arr.length);  // 4

// Модифікація
arr[1] = 'B';             // ['a', 'B', 'c', 'd']
arr[10] = 'z';            // розріджений масив! arr.length = 11

Стек і черга

JavaScript
const stack = [];

// СТЕК (LIFO): push/pop
stack.push(1, 2, 3);     // [1, 2, 3]
console.log(stack.pop()); // 3 — знімає з кінця

// ЧЕРГА (FIFO): push/shift
const queue = [];
queue.push('a');
queue.push('b');
console.log(queue.shift()); // "a" — знімає з початку
// shift/unshift — O(n): зсувають всі елементи. Для великих черг — використовуйте deque або linked list

// unshift — додає на початок
queue.unshift('first');  // ['first', 'b']

splice і slice

JavaScript
const arr = [1, 2, 3, 4, 5];

// slice — копія підмасиву (НЕ мутує)
console.log(arr.slice(1, 3));   // [2, 3]
console.log(arr.slice(-2));     // [4, 5]
console.log(arr);               // [1, 2, 3, 4, 5] — незмінний

// splice — видалення/вставка (МУТУЄ масив!)
const removed = arr.splice(1, 2); // видалити 2 елементи з позиції 1
console.log(removed); // [2, 3]
console.log(arr);     // [1, 4, 5]

arr.splice(1, 0, 'a', 'b'); // вставити без видалення
console.log(arr); // [1, 'a', 'b', 4, 5]

Пошук

JavaScript
const items = [1, 2, 3, 4, 2, 5];

console.log(items.indexOf(2));          // 1 — перше входження
console.log(items.lastIndexOf(2));      // 4
console.log(items.indexOf(99));         // -1

console.log(items.includes(3));         // true (ES2016)
console.log(items.includes(NaN));       // false — indexOf теж не знайде NaN

// Для NaN: використовуйте find
const withNaN = [1, NaN, 3];
console.log(withNaN.find(x => Number.isNaN(x))); // NaN

Ітерація

JavaScript
const arr = ['a', 'b', 'c'];

// for...of (рекомендований для простої ітерації)
for (const item of arr) { console.log(item); }

// for...of з індексом
for (const [index, item] of arr.entries()) {
  console.log(index, item); // 0 'a', 1 'b', 2 'c'
}

// forEach (без break, без return значення)
arr.forEach((item, index) => { console.log(index, item); });

Підсумок

  • Масиви — об'єкти. typeof [] === "object". Перевіряйте через Array.isArray().
  • Стек: push/pop. Черга: push/shift (shift — O(n)).
  • slice не мутує. splice мутує — видаляє та вставляє елементи.
  • arr.at(-1) — останній елемент (ES2022).
  • Уникайте new Array(n) — створює розріджений масив.
