Примітиви — не об'єкти і не мають методів у звичайному розумінні. Але 'hello'.toUpperCase() працює. Це можливо завдяки autoboxing — тимчасовому обгортанню примітива в об'єкт на час виклику методу.

Autoboxing

При зверненні до методу примітива рушій автоматично:

  1. Створює тимчасовий об'єкт-обгортку (String, Number, або Boolean).
  2. Викликає метод через цей об'єкт.
  3. Знищує тимчасовий об'єкт і повертає результат.
JavaScript
const str = 'hello';
console.log(str.toUpperCase()); // "HELLO"
console.log(str.length);        // 5

// Внутрішньо (спрощено):
// 1. temp = new String('hello')
// 2. result = temp.toUpperCase()
// 3. temp знищується
// 4. повертається result

// Тому власні властивості не зберігаються
const s = 'test';
s.myProp = 42;          // temp об'єкт → знищено
console.log(s.myProp);  // undefined

Об'єктні обгортки — не використовуйте з new

JavaScript
// АНТИПАТЕРН: new String/Number/Boolean повертають об'єкти
const prim = 'hello';          // примітив
const obj  = new String('hello'); // об'єкт

console.log(typeof prim); // "string"
console.log(typeof obj);  // "object"  ← проблема
console.log(prim === obj); // false

const boolObj = new Boolean(false);
if (boolObj) console.log('виконується!'); // завжди true — об'єкт truthy!

// Без new — явна конвертація (OK, повертає примітив)
const n = Number('42');  // 42
const s = String(123);   // "123"
const b = Boolean(0);    // false

null і undefined — без обгорток

JavaScript
// TypeError: Cannot read properties of null
// null.toString();

// Захист: optional chaining
const val = null;
console.log(val?.toString()); // undefined — без помилки

Підсумок

  • Autoboxing: при виклику методу примітива — тимчасовий об'єкт-обгортка, використовується і знищується.
  • Ніколи new String/Number/Boolean — вони об'єкти зі несподіваною поведінкою.
  • null і undefined обгорток не мають — ?.method() для захисту.
