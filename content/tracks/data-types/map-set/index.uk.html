Map і Set — колекції ES6 що вирішують конкретні задачі краще ніж об'єкти та масиви: Map для пар ключ–значення з ключами будь-якого типу, Set для унікальних значень.

Map

Map — колекція пар ключ–значення де ключем може бути будь-який тип (включно з об'єктами і функціями). Гарантує порядок вставки. Методи: set, get, has, delete, clear, size.

JavaScript
const map = new Map();

// Ключі будь-якого типу
const keyObj = { id: 1 };
map.set('name',   'Alice');
map.set(42,       'число як ключ');
map.set(true,     'boolean ключ');
map.set(keyObj,   'об'єкт як ключ');

console.log(map.get('name'));  // "Alice"
console.log(map.get(42));      // "число як ключ"
console.log(map.get(keyObj));  // "об'єкт як ключ"
console.log(map.has('name'));  // true
console.log(map.size);         // 4

map.delete('name');
map.clear(); // очищає всю Map

// Ініціалізація з масиву пар
const map2 = new Map([
  ['host', 'localhost'],
  ['port', 3000],
]);

// Ітерація (гарантований порядок вставки)
for (const [key, value] of map2) {
  console.log(key, value);
}
// Або:
map2.forEach((value, key) => console.log(key, value));

Set

Set — колекція унікальних значень. Дублікати ігноруються. Методи: add, has, delete, clear, size.

JavaScript
const set = new Set([1, 2, 3, 2, 1]);
console.log(set.size);    // 3 — дублікати прибрані
console.log(set.has(2));  // true

set.add(4);
set.delete(1);
console.log([...set]);    // [2, 3, 4]

// Видалення дублікатів з масиву (класичний патерн)
const arr  = [1, 2, 2, 3, 3, 4];
const uniq = [...new Set(arr)]; // [1, 2, 3, 4]

// Перетин, об'єднання, різниця множин
const a = new Set([1, 2, 3, 4]);
const b = new Set([3, 4, 5, 6]);

const union        = new Set([...a, ...b]);         // {1,2,3,4,5,6}
const intersection = new Set([...a].filter(x => b.has(x))); // {3,4}
const difference   = new Set([...a].filter(x => !b.has(x))); // {1,2}

Підсумок

  • Map — ключ-значення. Ключ будь-якого типу. Гарантований порядок. Метод .size.
  • Set — унікальні значення. Дублікати ігноруються при add.
  • Map і Set є iterable: for...of, spread, деструктуризація.
  • Швидкий спосіб видалити дублікати: [...new Set(array)].
