Promise — об'єкт, що представляє майбутній результат асинхронної операції. Він може бути у трьох станах: pending, fulfilled або rejected. Після переходу стан незмінний.

Стани Promise

JavaScript
const p = new Promise((resolve, reject) => {
  // Executor виконується одразу і синхронно
  setTimeout(() => {
    const success = true;
    if (success) resolve('результат');  // fulfilled
    else reject(new Error('помилка'));  // rejected
  }, 1000);
});

// pending → fulfilled або pending → rejected
// Після переходу стан незмінний:
// resolve() після reject() або навпаки — ігнорується

then / catch / finally

JavaScript
const promise = fetch('https://api.example.com/data');

promise
  .then(response => response.json())   // fulfilled → обробка
  .then(data => console.log(data))     // ланцюжок
  .catch(err => console.error(err))    // будь-яка помилка в ланцюжку
  .finally(() => console.log('done')); // завжди, незалежно від результату

// .then(onFulfilled, onRejected) — повна форма
promise.then(
  result => console.log('OK:', result),
  error  => console.log('Err:', error)
);

Ланцюжок Promise

JavaScript
// Кожен .then повертає новий Promise
Promise.resolve(1)
  .then(n => n + 1)      // 2
  .then(n => n * 3)      // 6
  .then(n => {
    if (n > 5) throw new Error('too big');
    return n;
  })
  .catch(err => {
    console.log(err.message); // 'too big'
    return 0;                 // відновлення — ланцюжок продовжується
  })
  .then(n => console.log('final:', n)); // 'final: 0'

// Повернення Promise всередині .then → очікування
function delay(ms) {
  return new Promise(resolve => setTimeout(resolve, ms));
}

delay(500).then(() => delay(500)).then(() => console.log('1 секунда'));

Утилітарні конструктори

JavaScript
// Вже fulfilled
Promise.resolve(42).then(console.log); // 42

// Вже rejected
Promise.reject(new Error('fail')).catch(console.error);

// Обгортання callback-API
function readFilePromise(path) {
  return new Promise((resolve, reject) => {
    fs.readFile(path, 'utf8', (err, data) => {
      if (err) reject(err);
      else resolve(data);
    });
  });
}

Ніколи не забувай .catch() — необроблений rejected Promise видає попередження у браузері та крашить процес у Node.js (з версії 15+).

Підсумок

  • Promise: pending → fulfilled | rejected (незворотньо)
  • .then() повертає новий Promise — основа ланцюжків
  • .catch(e) = .then(null, e) — ловить помилки всього ланцюжка вище
  • .finally() — для cleanup, не отримує аргументів
  • Завжди додавай .catch() до кожного ланцюжка
