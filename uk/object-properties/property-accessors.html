Гетери і сетери властивостей

СереднійВластивості об'єктів, їх конфігурація~ 11 хв

Аксесори (accessor properties) — властивості-функції, що виглядають як звичайні властивості. get викликається при читанні, set — при записі. Дозволяють обчислювані або захищені властивості без зміни публічного інтерфейсу.

get і set

JavaScript
const user = {
  firstName: 'Олена',
  lastName:  'Коваль',

  // Обчислювана властивість
  get fullName() {
    return `${this.firstName} ${this.lastName}`;
  },

  set fullName(value) {
    const parts = value.trim().split(' ');
    this.firstName = parts[0];
    this.lastName  = parts[1] ?? '';
  },
};

console.log(user.fullName);        // "Олена Коваль" — викликає get
user.fullName = 'Андрій Серга';    // викликає set
console.log(user.firstName);       // "Андрій"
console.log(user.lastName);        // "Серга"

Валідація через set

JavaScript
class Temperature {
  #celsius = 0;  // приватне поле

  get celsius() { return this.#celsius; }
  set celsius(value) {
    if (typeof value !== 'number') throw new TypeError('Must be a number');
    if (value < -273.15) throw new RangeError('Below absolute zero');
    this.#celsius = value;
  }

  get fahrenheit() { return this.#celsius * 9/5 + 32; }
  set fahrenheit(value) { this.celsius = (value - 32) * 5/9; }
}

const t = new Temperature();
t.celsius = 100;
console.log(t.fahrenheit);  // 212
t.fahrenheit = 32;
console.log(t.celsius);     // 0
// t.celsius = -300;        // RangeError

Аксесор через defineProperty

JavaScript
const obj = { _name: 'Alice' };

Object.defineProperty(obj, 'name', {
  get() { return this._name; },
  set(value) { this._name = value.trim(); },
  enumerable:   true,
  configurable: true,
});

obj.name = '  Bob  ';
console.log(obj.name); // "Bob" — trim() у сетері

Підсумок

  • get prop() — виклик при читанні. set prop(value) — при записі.
  • Аксесор не має value і writable в дескрипторі — лише get, set, enumerable, configurable.
  • Валідація, обчислювані значення, приватний стан без зміни публічного API.
