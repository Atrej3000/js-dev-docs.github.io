Юнікод: внутрішня будова рядків

СереднійРізне~ 11 хв

JavaScript рядки — послідовності кодових одиниць UTF-16. Символи поза BMP (Basic Multilingual Plane) кодуються двома кодовими одиницями (surrogate pairs). Це пояснює чому деякі символи мають length === 2.

UTF-16 і surrogate pairs

JavaScript
// BMP символи: одна кодова одиниця
console.log('A'.length);  // 1
console.log('А'.length);  // 1 (кирилиця)

// Символи поза BMP: дві кодові одиниці
// Unicode escape для emoji U+1F600:
const emoji = '\u{1F600}';  // "😀"
console.log(emoji.length);  // 2  -- дві code units!

// codePointAt -- правильне отримання code point
console.log(emoji.codePointAt(0).toString(16)); // "1f600"

// String.fromCodePoint -- правильне створення
console.log(String.fromCodePoint(0x1f600)); // emoji символ

// charCodeAt: окремі surrogate halves
console.log(emoji.charCodeAt(0).toString(16)); // "d83d" (high surrogate)
console.log(emoji.charCodeAt(1).toString(16)); // "de00" (low surrogate)

Ітерація по символах

JavaScript
// Рядок: A + emoji(U+1F600) + B
const str = 'A\u{1F600}B';

// for...of ітерує по code points (правильно)
const chars = [];
for (const ch of str) chars.push(ch);
console.log(chars.length);  // 3 (A, emoji, B)

// Spread теж по code points
console.log([...str].length);  // 3

// str[index] -- кодові одиниці (може розрізати surrogate pair)
console.log(str.length);       // 4 (emoji займає 2 позиції)
console.log([...str].length);  // 3 (правильна кількість символів)

Unicode нормалізація

JavaScript
// "é" можна представити двома способами
const composed   = '\u00e9';   // composed: 1 code point
const decomposed = 'e\u0301'; // decomposed: e + combining accent (2)

console.log(composed === decomposed);  // false
console.log(composed.length);          // 1
console.log(decomposed.length);        // 2

// normalize для коректного порівняння
const n1 = composed.normalize('NFC');
const n2 = decomposed.normalize('NFC');
console.log(n1 === n2); // true

Підсумок

  • JS рядки — UTF-16. Символи поза BMP (emoji, рідкісні символи) = 2 кодові одиниці, length === 2.
  • codePointAt() / String.fromCodePoint() — правильна робота з code points.
  • for...of і spread ітерують по code points.
  • normalize('NFC') — уніфіковане представлення перед порівнянням.
