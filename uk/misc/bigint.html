BigInt

СереднійРізне~ 8 хв

BigInt — числовий тип для цілих чисел довільної точності. Вирішує проблему Number.MAX_SAFE_INTEGER: звичайні числа точні лише до 2⁵³-1. BigInt потрібен для криптографії, ID з бекенду (64-bit), фінансових розрахунків.

Створення

JavaScript
// Суфікс n
const big = 9007199254740993n;  // більше MAX_SAFE_INTEGER

// BigInt()
BigInt(42);          // 42n
BigInt('12345678901234567890'); // з рядка

// Порівняння з Number
Number.MAX_SAFE_INTEGER;        // 9007199254740991
9007199254740992 === 9007199254740993; // true (!) — Number втрачає точність
9007199254740992n === 9007199254740993n; // false — BigInt точний

typeof 42n; // 'bigint'

Операції

JavaScript
// Арифметика — лише між BigInt
10n + 20n;   // 30n
10n * 3n;    // 30n
10n / 3n;    // 3n (цілочисельне ділення, без дробів!)
10n % 3n;    // 1n
2n ** 100n;  // величезне число

// Змішувати Number і BigInt — TypeError
// 10n + 5;  // TypeError: Cannot mix BigInt and other types

// Явне перетворення
10n + BigInt(5);  // 15n
Number(10n) + 5;  // 15 (але можлива втрата точності для великих)

// Порівняння — можна між собою (не строга рівність з Number)
1n == 1;    // true (нестрога — тип ігнорується)
1n === 1;   // false (строга — різні типи)
2n > 1;     // true (порівняння — дозволено)

Обмеження

JavaScript
// НЕ працює з методами Math
// Math.max(1n, 2n); // TypeError

// НЕ дробові числа
// 1.5n;  // SyntaxError

// JSON.stringify не підтримує BigInt
// JSON.stringify(42n); // TypeError
// Рішення:
JSON.stringify(42n, (key, val) =>
  typeof val === 'bigint' ? val.toString() : val
); // '"42"'

// Серіалізація/десеріалізація
const id = BigInt('9007199254740993');
const json = `{"id": "${id}"}`;          // зберігаємо як рядок
const parsed = BigInt(JSON.parse(json).id); // відновлюємо

Де реально потрібен

JavaScript
// 1. Великі ID з бекенду (Twitter Snowflake ID, PostgreSQL int8)
const tweetId = 1234567890123456789n;

// 2. Криптографія
function modPow(base, exp, mod) {
  let result = 1n;
  base = base % mod;
  while (exp > 0n) {
    if (exp % 2n === 1n) result = (result * base) % mod;
    exp = exp / 2n;
    base = (base * base) % mod;
  }
  return result;
}

// 3. Точні фінансові обчислення (в копійках/центах)
const price  = 1999n; // 19.99 грн → зберігаємо у копійках
const qty    = 3n;
const total  = price * qty; // 5997n = 59.97 грн

Для роботи з BigInt у JSON-API: домовитесь з бекендом передавати великі числа як рядки. Більшість мов (Go, Java, Python) підтримують 64-bit int, але JSON spec не гарантує точність за межами 2⁵³.

Підсумок

  • BigInt — цілі числа будь-якої величини без втрати точності
  • Синтаксис: 42n або BigInt(42)
  • Не змішується з Number в арифметиці (але порівняння нестроге — ОК)
  • Без дробів, без Math.*, без JSON out-of-the-box
  • Кейси: великі ID, криптографія, фінансові суми у копійках
