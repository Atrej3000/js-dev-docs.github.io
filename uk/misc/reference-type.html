Reference Type

ПросунутийРізне~ 8 хв

Reference Type — внутрішній механізм специфікації JS, що пояснює, чому одні виклики методів зберігають this, а інші — ні. Знання цього допомагає передбачати поведінку this без магічного мислення.

Проблема втрати this

JavaScript
const user = {
  name: 'Alice',
  greet() { return `Hello, ${this.name}`; }
};

user.greet();           // 'Hello, Alice' — this = user

const fn = user.greet;
fn();                   // 'Hello, undefined' — this = undefined (strict) або window

// Чому? Розберемо через Reference Type

Що таке Reference Type

JavaScript
// Reference Type — це специфікаційний тип (не реальний JS-тип)
// Він зберігає три компоненти:
// { base: об'єкт, name: ім'я властивості, strict: режим }

// user.greet — це Reference: { base: user, name: 'greet' }
// При виклику user.greet() — JS бере base як this → this = user

// const fn = user.greet — присвоєння витягує значення (саму функцію)
// Reference втрачається — this = undefined (strict)

// Операції, що руйнують Reference Type:
const { greet } = user;    // деструктуризація
greet();                    // this = undefined

const fn2 = (true ? user.greet : null);
fn2();                      // умовний вираз — Reference втрачена, this = undefined

const fn3 = (user.greet);   // дужки без аргументів — зберігає Reference
fn3.call(user);             // але сам виклик вже з правильним this

Кейси поведінки this

JavaScript
const obj = {
  val: 42,
  getVal() { return this.val; },
  arrow: () => console.log(this), // this з outer scope (не obj)
};

// ✅ Зберігають this (Reference цілий)
obj.getVal();                   // 42
obj['getVal']();                // 42

// ❌ Руйнують Reference
const f1 = obj.getVal;
f1();                           // undefined

const f2 = (obj.getVal);
// Виклик f2() — Reference вже не збережена в f2

// setTimeout — завжди втрачає this
setTimeout(obj.getVal, 100);    // undefined — передається копія функції

// Рішення 1: bind
setTimeout(obj.getVal.bind(obj), 100); // 42

// Рішення 2: стрілка
setTimeout(() => obj.getVal(), 100);   // 42

// Рішення 3: arrow method у класі
class C {
  val = 42;
  getVal = () => this.val; // стрілка — this завжди прив'язаний
}

Reference Type — концепція зі специфікації ECMAScript, а не реальний тип даних. Вона описує внутрішній механізм. Програмісту достатньо знати правило: виклик через крапку або дужки зберігає this; присвоєння, деструктуризація, передача аргументом — руйнує.

Підсумок

  • obj.method() — Reference ціла → this = obj
  • Присвоєння, деструктуризація, умовний вираз — Reference руйнується → this = undefined
  • Рішення: .bind(), стрілкова функція-обгортка, class field arrow
  • Стрілкові функції не мають власного this — не залежать від Reference Type
