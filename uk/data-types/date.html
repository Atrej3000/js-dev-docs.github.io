Дата і час

СереднійТипи даних~ 14 хв

Date — вбудований клас для роботи з датою та часом. Внутрішньо зберігає мілісекунди від Unix epoch (1 січня 1970 UTC). Клас має чимало пасток: місяці від 0, локальні vs UTC методи, відсутність часових зон.

Створення

JavaScript
// Поточний момент
const now = new Date();

// З мілісекунд (timestamp)
const d1 = new Date(0);           // 1970-01-01T00:00:00.000Z
const d2 = new Date(1000 * 3600); // +1 година від epoch

// З рядка (ISO 8601 рекомендований)
const d3 = new Date('2024-03-15');
const d4 = new Date('2024-03-15T10:30:00Z');

// З компонентів (місяць від 0!)
const d5 = new Date(2024, 2, 15, 10, 30, 0); // 15 березня 2024
//                        ^ 2 = березень (0-indexed)

// Timestamp
Date.now();      // поточний timestamp, швидше ніж new Date().getTime()
d4.getTime();    // мілісекунди

Читання компонентів

JavaScript
const d = new Date('2024-03-15T10:30:45.123Z');

// Локальний час (залежить від системної TZ)
d.getFullYear();     // 2024
d.getMonth();        // 2 (березень — 0-indexed!)
d.getDate();         // 15 (день місяця)
d.getDay();          // 5 (п'ятниця, 0=неділя)
d.getHours();        // залежить від TZ
d.getMinutes();      // 30
d.getSeconds();      // 45
d.getMilliseconds(); // 123

// UTC версії
d.getUTCFullYear();  // 2024
d.getUTCHours();     // 10 (UTC, не залежить від TZ)
d.getUTCMonth();     // 2

// Timestamp
d.getTime();         // ms від epoch

Модифікація

JavaScript
const d = new Date('2024-01-15');

d.setFullYear(2025);     // змінює рік
d.setMonth(5);           // червень (0-indexed)
d.setDate(d.getDate() + 7); // +7 днів

// Авто-корекція: Date коригує некоректні значення
const weird = new Date(2024, 1, 31); // 31 лютого
console.log(weird);  // 2024-03-02 — автоматично перенесено!

const backtrack = new Date(2024, 2, 0); // 0-й день березня
console.log(backtrack); // 2024-02-29 — останній день лютого

Авто-корекція Date зручна для арифметики: setDate(date.getDate() + N) коректно переходить через межі місяців і років.

Форматування

JavaScript
const d = new Date('2024-03-15T10:30:00');

// Вбудовані методи
d.toString();      // 'Fri Mar 15 2024 10:30:00 GMT+0200'
d.toISOString();   // '2024-03-15T08:30:00.000Z' (UTC!)
d.toLocaleDateString('uk-UA'); // '15.03.2024'
d.toLocaleTimeString('uk-UA'); // '10:30:00'
d.toLocaleString('uk-UA', {
  day: '2-digit', month: 'long', year: 'numeric'
}); // '15 березня 2024 р.'

// Intl.DateTimeFormat (рекомендовано для production)
const fmt = new Intl.DateTimeFormat('uk-UA', {
  weekday: 'long', year: 'numeric', month: 'long', day: 'numeric'
});
fmt.format(d); // 'п'ятниця, 15 березня 2024 р.'

Різниця між датами

JavaScript
const start = new Date('2024-01-01');
const end   = new Date('2024-03-15');

const diffMs   = end - start;          // різниця в мілісекундах
const diffDays = diffMs / (1000*60*60*24); // ~74.x днів

// Вік людини
function age(birthDate) {
  const diff = Date.now() - new Date(birthDate).getTime();
  return Math.floor(diff / (1000*60*60*24*365.25));
}
console.log(age('1990-05-20')); // кількість повних років

Підводні камені

1. Місяці від 0 — найпоширеніша помилка. 2. new Date(string) без ізо-формату може вести себе по-різному в різних браузерах. 3. Методи без UTC повертають локальний час — результат залежить від машини.

Підсумок

  • Місяці 0–11, дні тижня 0–6 (неділя=0)
  • Date.now() — найшвидший спосіб отримати timestamp
  • Завжди використовуй ISO-рядки при парсингу
  • Для UTC: методи getUTC* / setUTC*
  • Авто-корекція дозволяє просту арифметику дат
  • Для серйозної роботи з датами — бібліотека date-fns або Temporal API
