JSON, методи toJSON

ПочатковийТипи даних~ 11 хв

JSON (JavaScript Object Notation) — текстовий формат обміну даними. JSON.stringify серіалізує JavaScript-значення у JSON-рядок, JSON.parse — парсить JSON-рядок назад у значення.

JSON.stringify

JavaScript
const data = {
  name:   'Alice',
  age:    30,
  scores: [95, 87, 92],
  active: true,
};

// Базова серіалізація
console.log(JSON.stringify(data));
// '{"name":"Alice","age":30,"scores":[95,87,92],"active":true}'

// З відступами для читабельності
console.log(JSON.stringify(data, null, 2));
// {
//   "name": "Alice",
//   ...
// }

// Що НЕ серіалізується (пропускається або стає null):
const problematic = {
  fn:       () => {},      // → пропускається
  undef:    undefined,     // → пропускається
  sym:      Symbol('s'),   // → пропускається
  nan:      NaN,           // → null
  inf:      Infinity,      // → null
  date:     new Date(),    // → ISO рядок
  regex:    /abc/,         // → {}
};
console.log(JSON.stringify(problematic));
// '{"nan":null,"inf":null,"date":"2026-...","regex":{}}'

Replacer-функція і масив

JavaScript
const user = { name: 'Alice', password: 'secret', age: 30 };

// Масив ключів — включити тільки вказані
console.log(JSON.stringify(user, ['name', 'age']));
// '{"name":"Alice","age":30}' — password прихований

// Функція: (key, value) → що серіалізувати
const result = JSON.stringify(user, (key, value) => {
  if (key === 'password') return undefined; // пропустити
  if (typeof value === 'number') return value * 2; // подвоїти числа
  return value;
});
// '{"name":"Alice","age":60}'

JSON.parse і reviver

JavaScript
const json = '{"name":"Alice","age":30,"scores":[95,87]}';

const parsed = JSON.parse(json);
console.log(parsed.name);    // "Alice"
console.log(parsed.scores);  // [95, 87]

// Помилка при невалідному JSON
try {
  JSON.parse('{invalid}');
} catch (e) {
  console.log(e instanceof SyntaxError); // true
}

// Reviver: відновлення типів (наприклад Date)
const withDate = '{"name":"Bob","birthday":"2000-01-15T00:00:00.000Z"}';

const user = JSON.parse(withDate, (key, value) => {
  if (key === 'birthday') return new Date(value);
  return value;
});
console.log(user.birthday instanceof Date); // true

toJSON

JavaScript
// Якщо об'єкт має метод toJSON — stringify використає його результат
class Money {
  constructor(amount, currency) {
    this.amount   = amount;
    this.currency = currency;
  }
  toJSON() {
    return `${this.amount} ${this.currency}`;
  }
}

const price = new Money(1500, 'UAH');
console.log(JSON.stringify({ price }));
// '{"price":"1500 UAH"}'

// Date.prototype.toJSON() повертає ISO рядок — тому Date серіалізується

Підсумок

  • JSON.stringify(value, replacer, space) → рядок. Функції, undefined, Symbol — пропускаються.
  • JSON.parse(str, reviver) → JavaScript значення. Кидає SyntaxError при невалідному JSON.
  • Replacer-масив — білий список ключів. Replacer-функція — гнучке фільтрування/трансформація.
  • Reviver — відновлення типів (Date тощо) при парсингу.
  • Метод toJSON на об'єкті — контролює серіалізацію.
