Методи масивів

ПочатковийТипи даних~ 17 хв

Масиви мають потужний набір методів вищого порядку. Більшість з них приймають callback-функцію і дозволяють описувати що робити з даними, а не як ітерувати — функціональний підхід без явних циклів.

Трансформація: map

JavaScript
const prices = [100, 200, 350, 80];

// map: перетворює кожен елемент, повертає новий масив
const withTax = prices.map(price => price * 1.2);
console.log(withTax); // [120, 240, 420, 96]

// map з index і array
const indexed = prices.map((price, i) => ({ id: i + 1, price }));
// [{ id:1, price:100 }, { id:2, price:200 }, ...]

// map не мутує оригінал
console.log(prices); // [100, 200, 350, 80]

Фільтрація: filter

JavaScript
const users = [
  { name: 'Alice', age: 25, active: true  },
  { name: 'Bob',   age: 17, active: false },
  { name: 'Carol', age: 30, active: true  },
];

// filter: залишає елементи де callback повертає truthy
const adults       = users.filter(u => u.age >= 18);
const activeAdults = users.filter(u => u.active && u.age >= 18);

console.log(adults.length);       // 2 (Alice, Carol)
console.log(activeAdults.length); // 2

Редукція: reduce

JavaScript
const numbers = [1, 2, 3, 4, 5];

// reduce(callback, initialValue)
// callback(accumulator, currentValue, index, array)
const sum = numbers.reduce((acc, n) => acc + n, 0);
console.log(sum); // 15

// Без initialValue: перший елемент = accumulator
const max = numbers.reduce((acc, n) => (n > acc ? n : acc));
console.log(max); // 5

// Групування об'єктів
const people = [
  { name: 'Alice', dept: 'eng' },
  { name: 'Bob',   dept: 'hr'  },
  { name: 'Carol', dept: 'eng' },
];

const byDept = people.reduce((acc, person) => {
  const dept = acc[person.dept] || [];
  return { ...acc, [person.dept]: [...dept, person] };
}, {});
// { eng: [Alice, Carol], hr: [Bob] }

Пошук: find, findIndex, some, every

JavaScript
const items = [
  { id: 1, name: 'Laptop', price: 1200 },
  { id: 2, name: 'Mouse',  price: 25   },
  { id: 3, name: 'KB',     price: 80   },
];

// find: перший збіг або undefined
const expensive = items.find(item => item.price > 100);
console.log(expensive); // { id:1, name:'Laptop', ... }

// findIndex: індекс першого збігу або -1
const idx = items.findIndex(item => item.id === 2);
console.log(idx); // 1

// some: чи є хоча б один елемент що відповідає умові
console.log(items.some(item => item.price > 1000));  // true

// every: чи всі елементи відповідають умові
console.log(items.every(item => item.price > 0));    // true
console.log(items.every(item => item.price > 100));  // false

Сортування: sort

JavaScript
// АНТИПАТЕРН: sort без функції порівняння
const nums = [10, 1, 21, 2];
console.log(nums.sort()); // [1, 10, 2, 21] — лексикографічно!

// ПРАВИЛЬНО: функція порівняння
nums.sort((a, b) => a - b);   // [1, 2, 10, 21] — зростання
nums.sort((a, b) => b - a);   // [21, 10, 2, 1] — спадання

// Сортування рядків
const words = ['banana', 'apple', 'cherry'];
words.sort((a, b) => a.localeCompare(b, 'uk')); // Ukrainian locale

// Сортування об'єктів
const people = [{ name: 'Bob' }, { name: 'Alice' }, { name: 'Carol' }];
people.sort((a, b) => a.name.localeCompare(b.name));
// [Alice, Bob, Carol]

// sort МУТУЄ оригінальний масив!
// Для незмінного: [...arr].sort(...)

flat і flatMap

JavaScript
// flat: розгладжує вкладені масиви
const nested = [1, [2, 3], [4, [5, 6]]];
console.log(nested.flat());   // [1, 2, 3, 4, [5, 6]] — один рівень
console.log(nested.flat(2));  // [1, 2, 3, 4, 5, 6] — два рівні
console.log(nested.flat(Infinity)); // будь-яка глибина

// flatMap: map + flat(1) — ефективніше ніж окремі виклики
const sentences = ['Hello world', 'foo bar'];
const words = sentences.flatMap(s => s.split(' '));
console.log(words); // ['Hello', 'world', 'foo', 'bar']

Ланцюги методів

JavaScript
const orders = [
  { id: 1, amount: 150, paid: true  },
  { id: 2, amount: 80,  paid: false },
  { id: 3, amount: 220, paid: true  },
  { id: 4, amount: 45,  paid: true  },
];

// Сума оплачених замовлень понад 100
const total = orders
  .filter(o => o.paid)
  .filter(o => o.amount > 100)
  .reduce((sum, o) => sum + o.amount, 0);

console.log(total); // 370 (150 + 220)

Підсумок

  • map → новий масив тієї ж довжини. filter → підмасив. reduce → одне значення.
  • find → перший елемент або undefined. findIndex → індекс або -1.
  • some → true якщо хоча б один збігається. every → true якщо всі.
  • sort без функції — лексикографічне. Для чисел — завжди передавайте (a, b) => a - b.
  • sort мутує оригінал. Для незмінного — [...arr].sort().
  • flat(depth) — розгладжує вкладені. flatMap = map + flat(1).
