Деструктуризоване присвоєння

ПочатковийТипи даних~ 13 хв

Деструктуризація — синтаксис ES6 для розпаковування значень із масивів або властивостей з об'єктів у окремі змінні. Замінює серію присвоєнь і робить код лаконічнішим.

Деструктуризація масивів

JavaScript
const arr = [1, 2, 3, 4, 5];

// Базова
const [a, b, c] = arr;      // a=1, b=2, c=3

// Пропуск елементів через кому
const [first, , third] = arr; // first=1, third=3

// Rest-елемент
const [head, ...tail] = arr;  // head=1, tail=[2,3,4,5]

// Значення за замовчуванням
const [x = 10, y = 20] = [1];  // x=1, y=20

// Обмін змінних без тимчасової
let p = 1, q = 2;
[p, q] = [q, p];  // p=2, q=1

// З ітерованих
const [ch1, ch2] = 'hi';   // ch1='h', ch2='i'

Деструктуризація об'єктів

JavaScript
const user = { name: 'Олена', age: 28, role: 'admin', city: 'Київ' };

// Базова: змінна = ключ
const { name, age } = user;

// Перейменування: ключ: нова_змінна
const { name: userName, role: userRole } = user;
console.log(userName); // "Олена"

// Значення за замовчуванням
const { name: n, level = 1 } = user; // level = 1 (відсутній у user)

// Rest для решти властивостей
const { name: nm, ...rest } = user;
console.log(rest); // { age: 28, role: 'admin', city: 'Київ' }

Вкладена деструктуризація

JavaScript
const config = {
  db: { host: 'localhost', port: 5432 },
  server: { port: 3000 },
};

// Вкладений об'єкт
const { db: { host, port: dbPort }, server: { port: serverPort } } = config;
console.log(host, dbPort, serverPort); // "localhost" 5432 3000

// Масив в об'єкті
const { coords: [lat, lng] } = { coords: [50.45, 30.52] };
console.log(lat, lng); // 50.45 30.52

Деструктуризація в параметрах функції

JavaScript
// Замість function createUser(name, age, role)
function createUser({ name, age, role = 'user' }) {
  return { name, age, role, createdAt: Date.now() };
}

createUser({ name: 'Bob', age: 25 });
// { name: 'Bob', age: 25, role: 'user', createdAt: ... }

// Деструктуризація у for...of
const users = [{ name: 'Alice', age: 30 }, { name: 'Bob', age: 25 }];
for (const { name, age } of users) {
  console.log(name, age);
}

// З Object.entries
const scores = { math: 95, english: 87 };
for (const [subject, score] of Object.entries(scores)) {
  console.log(`${subject}: ${score}`);
}

Підсумок

  • Масив: const [a, b] = arr. Пропуск через кому. Rest ...tail.
  • Об'єкт: const { key } = obj. Перейменування: { key: var }. Дефолт: { key = val }.
  • Вкладена: { outer: { inner } } = obj.
  • Обмін: [a, b] = [b, a] — без тимчасової змінної.
  • Деструктуризація в параметрах функції — кращий підхід ніж багато позиційних параметрів.
