Коментарі

ПочатковийЯкість коду~ 10 хв

Коментар — це текст для людей, не для рушія. Хороший коментар пояснює чому прийнято рішення, а не що робить код. Останнє має бути зрозумілим з самого коду.

Антипатерни: що не варто коментувати

JavaScript
// ПОГАНО: коментар переказує код
// Збільшуємо лічильник на 1
count++;

// Перевіряємо чи user активний
if (user.isActive) { /* ... */ }

// ПОГАНО: застарілий коментар (гірше за відсутність)
// Повертає рядок з ім'ям
function getUserId(user) {  // насправді повертає number
  return user.id;
}

// ПОГАНО: закоментований код — видаляйте, git пам'ятає
// const oldResult = calculate(x);
// return oldResult * 2;
return calculate(x) * 2;

Що варто коментувати

JavaScript
// ДОБРЕ: пояснює неочевидне рішення
// Зміщення на -1 компенсує 0-базовану індексацію зовнішнього API (spec §4.2)
const apiIndex = localIndex - 1;

// ДОБРЕ: попереджає про пастку
// parseInt без основи повертає вісімкову для рядків з провідним 0 у старих браузерах
const parsed = parseInt(input, 10);

// ДОБРЕ: пояснює бізнес-правило
// Мінімальний вік відповідно до GDPR Art. 8 для юрисдикцій без відомого порогу
const MINIMUM_AGE = 16;

// ДОБРЕ: посилання на зовнішній контекст
// Обхід бага Chrome #1234567: requestAnimationFrame не викликається
// у прихованих iframe без цього setTimeout
setTimeout(() => requestAnimationFrame(render), 0);

JSDoc

JSDoc — стандарт документування публічних API. Редактори (VS Code, WebStorm) використовують JSDoc для IntelliSense — підказок при автодоповненні.

JavaScript
/**
 * Обчислює вартість замовлення з урахуванням знижки.
 *
 * @param {number} subtotal - Сума до знижки (гривні)
 * @param {number} discountRate - Ставка знижки (0–1), наприклад 0.1 = 10%
 * @param {boolean} [includeTax=true] - Чи включати ПДВ (20%)
 * @returns {number} Фінальна вартість
 * @throws {RangeError} Якщо discountRate поза діапазоном [0, 1]
 *
 * @example
 * calculateTotal(100, 0.1)       // 108 (зі знижкою і ПДВ)
 * calculateTotal(100, 0.1, false) // 90  (зі знижкою, без ПДВ)
 */
function calculateTotal(subtotal, discountRate, includeTax = true) {
  if (discountRate < 0 || discountRate > 1) {
    throw new RangeError(`discountRate must be 0–1, got ${discountRate}`);
  }
  const discounted = subtotal * (1 - discountRate);
  return includeTax ? discounted * 1.2 : discounted;
}

Самодокументований код

Найкращий коментар — той, що не потрібен. Ясне іменування і правильна структура часто роблять коментар зайвим.

JavaScript
// ПОТРЕБУЄ КОМЕНТАРЯ — незрозуміла назва
const d = new Date();
const ts = d.getTime() / 1000; // перетворення мс → секунди

// САМОДОКУМЕНТОВАНИЙ — коментар не потрібен
const now = new Date();
const unixTimestampSeconds = Math.floor(now.getTime() / 1000);

// ПОТРЕБУЄ КОМЕНТАРЯ — магічне число
if (status > 2) { return; }

// САМОДОКУМЕНТОВАНИЙ
const MAX_RETRY_STATUS = 2;
if (retryCount > MAX_RETRY_STATUS) { return; }

Підсумок

  • Коментар пояснює чому, не що. Код має пояснювати себе сам.
  • Не коментуйте очевидне. Видаляйте закоментований код — git зберігає історію.
  • JSDoc для публічного API: @param, @returns, @throws, @example.
  • TODO/FIXME — з поясненням і посиланням на трекер.
  • Застарілий коментар гірше за відсутність — вводить в оману.
