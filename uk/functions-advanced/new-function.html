Синтаксис new Function

СереднійРозширена робота з функціями~ 8 хв

Синтаксис new Function(...args, body) дозволяє створювати функції динамічно з рядка коду. Особливість: такі функції замикаються на глобальний scope, а не на scope місця створення. Це важливо для мінімізаторів і серіалізації.

Синтаксис

JavaScript
// new Function([...argNames], functionBody)
const add = new Function('a', 'b', 'return a + b');
console.log(add(2, 3)); // 5

// Без параметрів
const greet = new Function('return "Hello!"');
console.log(greet()); // 'Hello!'

// Кілька параметрів — різні варіанти запису
const fn1 = new Function('a', 'b', 'c', 'return a + b + c');
const fn2 = new Function('a,b,c', 'return a + b + c');
const fn3 = new Function('a, b, c', 'return a + b + c');
// Всі еквівалентні

Глобальний scope

JavaScript
const value = 'outer';

function createFn() {
  const value = 'inner';

  // Звичайна функція — замикання на inner scope
  const regular = () => value;

  // new Function — глобальний scope
  const dynamic = new Function('return value');

  console.log(regular()); // 'inner'
  // console.log(dynamic()); // ReferenceError або 'outer' (якщо value у global)
}
createFn();

Після мінімізації (minification) локальні змінні перейменовуються. Функція, створена через new Function, посилається на глобальний scope за іменем — і знайде лише те, що там є. Ніколи не покладайся на локальні змінні всередині new Function.

Де реально використовується

JavaScript
// 1. Отримання функції з сервера (template engine, formula evaluator)
async function loadValidator(serverCode) {
  // serverCode = "if (value < 0) return 'negative';"
  const validate = new Function('value', serverCode);
  return validate;
}

// 2. Динамічна компіляція шаблону
function compileTemplate(template) {
  // 'Hello, {{name}}!' → функція з підстановкою
  const body = 'return `' + template.replace(/{{(\w+)}}/g, '${data.$1}') + '`';
  return new Function('data', body);
}
const tmpl = compileTemplate('Hello, {{name}}! You are {{age}} years old.');
console.log(tmpl({ name: 'Alice', age: 30 }));

// 3. JSON.parse з eval — НЕ робіть так (небезпечно)
// const data = new Function('return ' + json)(); // вразливість XSS!

У безпечних середовищах new Function заблоковано Content Security Policy (CSP). Це ще одна причина використовувати його лише як останній засіб, а не загальний підхід.

Підсумок

  • new Function(args, body) — динамічна компіляція функції з рядка
  • Scope — завжди глобальний, не місця створення
  • Проблеми: мінімізатори зламають посилання на локальні змінні
  • Безпека: ніколи не підставляй у body дані від користувача — XSS
  • Реальне застосування: шаблонізатори, динамічні validators, отримані з сервера формули
