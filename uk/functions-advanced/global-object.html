Глобальний об'єкт

ПочатковийРозширена робота з функціями~ 8 хв

Глобальний об'єкт надає змінні та функції, доступні всюди. У браузері це window, у Node.js — global, а з ES2020 — стандартизований globalThis, що працює в будь-якому середовищі.

globalThis

JavaScript
// Єдиний стандартний спосіб (ES2020)
console.log(globalThis === window);  // true (браузер)
console.log(globalThis === global);  // true (Node.js)

// До ES2020 — обходи
const g = (typeof globalThis !== 'undefined') ? globalThis
        : (typeof window     !== 'undefined') ? window
        : (typeof global     !== 'undefined') ? global
        : this;

Глобальні змінні

JavaScript
// var на верхньому рівні стає властивістю globalThis (браузер)
var x = 10;
console.log(globalThis.x); // 10

// let/const НЕ стають властивістю globalThis
let y = 20;
console.log(globalThis.y); // undefined

// Явна глобальна змінна
globalThis.appConfig = { debug: false };

// Перевірка існування
if (!globalThis.Promise) {
  // поліфіл для старих середовищ
  globalThis.Promise = PolyfilledPromise;
}

Вбудовані глобалі

JavaScript
// Функції
parseInt('42px');     // 42
parseFloat('3.14em'); // 3.14
isNaN(NaN);           // true
isFinite(Infinity);   // false
encodeURI('https://example.com/path?q=привіт');
decodeURIComponent('%D0%BF%D1%80%D0%B8%D0%B2%D1%96%D1%82');

// Конструктори
new Array(), new Object(), new Map(), new Set()

// Значення
undefined, null, NaN, Infinity, -Infinity

// Браузерні глобалі (тільки window)
// setTimeout, setInterval, fetch, alert, document, location, history

Поліфіли через globalThis

JavaScript
// Перевірка і заповнення відсутньої функціональності
if (!globalThis.queueMicrotask) {
  globalThis.queueMicrotask = (fn) => Promise.resolve().then(fn);
}

// Feature detection без try/catch
const hasLocalStorage = 'localStorage' in globalThis;
const hasWebWorker    = 'Worker' in globalThis;

Уникай засмічення глобального простору. Кожна бібліотека, що додає власні глобалі, збільшує ризик конфліктів. Використовуй модулі (ESM) — вони мають власний scope.

Підсумок

  • globalThis — стандартний спосіб звертатись до глобального об'єкта в будь-якому середовищі
  • var на верхньому рівні = властивість globalThis; let/const — ні
  • Глобальний об'єкт містить вбудовані функції, конструктори та середовищні API
  • Поліфіли розміщуй через globalThis.X = ... після перевірки існування
