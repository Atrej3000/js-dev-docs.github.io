Promise API

СереднійПроміси, async/await~ 10 хв

Клас Promise має 6 статичних методів для роботи з кількома Promise одночасно. Кожен вирішує свою задачу: від «чекай на всі» до «бери перший результат».

Promise.all()

JavaScript
// Чекає на ВСІХ — відхиляється при першій помилці
const [user, orders, settings] = await Promise.all([
  fetch('/api/user').then(r => r.json()),
  fetch('/api/orders').then(r => r.json()),
  fetch('/api/settings').then(r => r.json()),
]);

// Порядок результатів = порядок вхідного масиву (не порядок виконання)

// Якщо будь-який відхилено — весь Promise.all відхиляється
Promise.all([
  Promise.resolve(1),
  Promise.reject(new Error('fail')),
  Promise.resolve(3),
]).catch(err => console.log(err.message)); // 'fail'
// Значення 1 і 3 втрачаються!

Promise.allSettled()

JavaScript
// Чекає на ВСІХ — ніколи не відхиляється
const results = await Promise.allSettled([
  fetch('/api/endpoint1').then(r => r.json()),
  fetch('/api/endpoint2').then(r => r.json()),
  Promise.reject(new Error('third failed')),
]);

results.forEach(result => {
  if (result.status === 'fulfilled') {
    console.log('OK:', result.value);
  } else {
    console.log('Err:', result.reason.message);
  }
});
// Навіть якщо частина запитів провалилась — маємо всі результати

Promise.race()

JavaScript
// Перший виконаний або відхилений — результат всього race
const result = await Promise.race([
  fetch('/api/primary'),
  fetch('/api/backup'),
]);

// Таймаут через race
function withTimeout(promise, ms) {
  const timeout = new Promise((_, reject) =>
    setTimeout(() => reject(new Error('Timeout')), ms)
  );
  return Promise.race([promise, timeout]);
}

await withTimeout(fetch('/api/slow'), 3000);

Promise.any()

JavaScript
// Перший ВИКОНАНИЙ (ігнорує відхилення)
const fastest = await Promise.any([
  fetch('https://cdn1.example.com/data.json'),
  fetch('https://cdn2.example.com/data.json'),
  fetch('https://cdn3.example.com/data.json'),
]);
// Перший успішний CDN виграє

// Якщо всі відхилено → AggregateError
Promise.any([
  Promise.reject(new Error('e1')),
  Promise.reject(new Error('e2')),
]).catch(err => {
  console.log(err instanceof AggregateError); // true
  console.log(err.errors);  // [Error: e1, Error: e2]
});

Підсумок

  • Promise.all — паралельно, все або нічого
  • Promise.allSettled — паралельно, завжди всі результати
  • Promise.race — перший (будь-який результат)
  • Promise.any — перший успішний
