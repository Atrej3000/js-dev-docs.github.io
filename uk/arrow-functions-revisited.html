Повторення стрілкових функцій

СереднійФункції~ 10 хв

Стрілкові функції — це не просто скорочений синтаксис. Вони принципово відрізняються від звичайних функцій у тому, як обробляють this, arguments та конструктор. Ця стаття — поглиблений розгляд після вивчення bind, call/apply і замикань.

Відсутність власного this

JavaScript
// Стрілкова функція бере this з лексичного контексту (де написана)
class EventEmitter {
  constructor() {
    this.handlers = [];
  }

  on(handler) {
    // Стрілка — this з on (= екземпляр класу)
    this.handlers.push(() => handler.call(this));
  }

  emit() {
    this.handlers.forEach(h => h()); // this зберігається
  }
}

// bind/call/apply НЕ змінюють this стрілки
const arrow = () => console.log(this);
arrow.call({ x: 1 }); // виведе зовнішній this, не { x: 1 }

Відсутність arguments

JavaScript
// Звичайна функція: arguments доступний
function regularFn() {
  console.log(arguments); // Arguments [1, 2, 3]
}
regularFn(1, 2, 3);

// Стрілкова: arguments — це arguments зовнішньої функції
function outer() {
  const arrow = () => console.log(arguments);
  arrow(10, 20); // виводить arguments з outer, не [10, 20]!
}
outer(1, 2, 3); // Arguments [1, 2, 3]

// Правильна альтернатива для стрілок:
const arrowWithRest = (...args) => console.log(args);
arrowWithRest(1, 2, 3); // [1, 2, 3]

Коли використовувати стрілки

JavaScript
// ✓ Callbacks у методах масивів
const doubled = [1, 2, 3].map(x => x * 2);

// ✓ Promise chains
fetch('/api/users')
  .then(res => res.json())
  .then(users => users.filter(u => u.active));

// ✓ Callbacks усередині методів класу (зберігає this)
class DataService {
  constructor(data) { this.data = data; }

  process() {
    return this.data
      .filter(item => item.active)    // this.data доступне
      .map(item => this.transform(item)); // this.transform доступне
  }
  transform(item) { return { ...item, processed: true }; }
}

// ✗ НЕ для методів об'єкта
const obj = {
  value: 42,
  getValue: () => this.value, // this = globalThis, не obj!
  getValueCorrect() { return this.value; } // правильно
};

// ✗ НЕ для конструкторів
// const F = () => {};
// new F(); // TypeError: F is not a constructor

Підсумок

  • Стрілки не мають власного this: беруть з лексичного контексту. bind/call/apply не змінюють this.
  • Стрілки не мають arguments — використовуйте ...rest.
  • Стрілки не можна використовувати з new, не мають prototype.
  • Ідеальні для: callbacks у map/filter, Promise chains, callbacks у методах класу.
  • Не для: методів об'єкта, конструкторів, генераторів, функцій з arguments.
