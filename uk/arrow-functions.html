Стрілкові функції, основи

ПочатковийОснови JavaScript~ 12 хв

Стрілкові функції (arrow functions, ES6) — компактний синтаксис для функціональних виразів з лексичним this. Вони не є заміною звичайних функцій у всіх контекстах.

Синтаксис

JavaScript
// Повна форма
const add = (a, b) => {
  return a + b;
};

// Скорочена: один вираз — неявний return (без фігурних дужок)
const add2 = (a, b) => a + b;

// Один параметр — дужки необов'язкові
const double = n => n * 2;

// Без параметрів — порожні дужки обов'язкові
const getTimestamp = () => Date.now();

// Повернення літерального об'єкта — дужки обов'язкові (інакше {} = тіло)
const makeUser = (name, age) => ({ name, age });
// Без дужок: name => { name } — це тіло функції без return!

console.log(double(5));           // 10
console.log(getTimestamp());      // число
console.log(makeUser('Ann', 28)); // { name: 'Ann', age: 28 }

Лексичний this

Ключова відмінність: стрілкові функції не мають власного this. Вони беруть this з оточуючого лексичного контексту (звідки були створені).

JavaScript
// ПРОБЛЕМА зі звичайною функцією в методі
const timer = {
  seconds: 0,
  start() {
    setInterval(function() {
      this.seconds++; // this = globalThis або undefined (strict)!
      console.log(this.seconds);
    }, 1000);
  }
};
timer.start(); // NaN або помилка

// РІШЕННЯ: стрілкова функція бере this з методу start()
const timerFixed = {
  seconds: 0,
  start() {
    setInterval(() => {
      this.seconds++; // this = timerFixed — правильно
      console.log(this.seconds);
    }, 1000);
  }
};
timerFixed.start(); // 1, 2, 3...

// Стрілкова як метод об'єкта — АНТИПАТЕРН
const obj = {
  value: 42,
  getValue: () => this.value, // this = globalThis, не obj!
};
console.log(obj.getValue()); // undefined

// Метод об'єкта — завжди звичайна функція
const objFixed = {
  value: 42,
  getValue() { return this.value; },
};
console.log(objFixed.getValue()); // 42

// arguments недоступні — використовуйте rest params
const sum = (...args) => args.reduce((acc, n) => acc + n, 0);
console.log(sum(1, 2, 3, 4)); // 10

// new — TypeError
const Arrow = () => {};
// new Arrow(); // TypeError: Arrow is not a constructor

// bind/call/apply ігнорують зміну this
const obj = { x: 10 };
const getX = () => this.x;
console.log(getX.call(obj)); // undefined — this не змінився

Коли використовувати

  • Callbacks і короткі функції: .map, .filter, .reduce, обробники подій в методах класу.
  • Функції що потребують лексичного this: callback всередині методу.

Не використовуйте стрілкові функції для:

  • Методів об'єкта і класу (крім class fields).
  • Конструкторів.
  • Функцій з arguments.
  • Генераторів.

Підсумок

  • Стрілкові функції — компактний синтаксис + лексичний this.
  • Неявний return: вираз без фігурних дужок. Для об'єкта-літерала — в дужках: () => ({}).
  • Немає власного this, arguments, prototype. Не можна використовувати з new.
  • bind/call/apply не змінюють this стрілкової функції.
  • Для методів об'єкта — завжди звичайна функція (shorthand method або function expression).
