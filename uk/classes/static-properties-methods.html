Статичні властивості та методи

СереднійКласи~ 10 хв

Статичні методи та властивості належать класу, а не його екземплярам. Вони викликаються через ім'я класу і не доступні через this у звичайних методах. Успадковуються дочірніми класами.

Статичні методи

JavaScript
class MathHelper {
  static add(a, b)      { return a + b; }
  static multiply(a, b) { return a * b; }
  static PI = 3.14159;  // статична властивість
}

MathHelper.add(2, 3);       // 5 — через клас
MathHelper.PI;              // 3.14159

const m = new MathHelper();
// m.add(2, 3); // TypeError — немає в екземплярі
// m.PI;        // undefined

Статичні методи як фабрики

JavaScript
class User {
  constructor(name, role) {
    this.name = name;
    this.role = role;
  }

  static createAdmin(name) {
    return new User(name, 'admin');
  }

  static createGuest() {
    return new User('Guest', 'guest');
  }

  static fromObject({ name, role }) {
    return new User(name, role);
  }
}

const admin  = User.createAdmin('Alice');
const guest  = User.createGuest();
const parsed = User.fromObject({ name: 'Bob', role: 'editor' });

Статичне успадкування

JavaScript
class Animal {
  static kingdom = 'Animalia';
  static create(name) { return new this(name); } // this = клас, що викликає
}

class Dog extends Animal {
  constructor(name) { super(); this.name = name; }
  static type = 'Mammal';
}

console.log(Dog.kingdom);      // 'Animalia' — успадковано
console.log(Dog.type);         // 'Mammal' — власна
console.log(Animal.type);      // undefined

// this у статичному методі = клас, що викликає
const dog = Dog.create('Rex'); // new Dog('Rex')

Приватні статичні

JavaScript
class Config {
  static #instance = null;
  static #settings = { debug: false };

  static getInstance() {
    if (!Config.#instance) {
      Config.#instance = new Config();
    }
    return Config.#instance;
  }

  static setDebug(val) { Config.#settings.debug = val; }
  static isDebug()     { return Config.#settings.debug; }
}

Config.getInstance() === Config.getInstance(); // true — Singleton

Статичні методи — природне місце для: фабричних конструкторів, утиліт, пов'язаних з класом, паттерну Singleton, лічильників екземплярів.

Підсумок

  • Статичні методи/властивості — на класі, не на екземплярі
  • Успадковуються через ланцюжок прототипів класів (Dog.__proto__ === Animal)
  • this у статичному методі = клас, що викликав метод
  • Використовуй для: фабрик, утиліт, Singleton, лічильників, конфігурації
