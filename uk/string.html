Рядки

ПочатковийТипи даних~ 15 хв

Рядки в JavaScript — незмінні послідовності кодових одиниць UTF-16. Мають великий вбудований API для пошуку, модифікації і форматування. Усі методи повертають нові рядки — оригінал не змінюється.

Літерали і спеціальні символи

JavaScript
// Три типи лапок
const single   = 'Рядок в одинарних';
const double   = "Рядок в подвійних";
const template = `Шаблон: ${1 + 2} і багаторядковий
текст без \n`;

// Екранування
const withQuote  = 'it\'s fine';
const newline    = "рядок 1\nрядок 2";
const tab        = "col1\tcol2";
const unicode    = "\u0041";        // "A"
const codePoint  = "\u{1F600}";     // "😀" (ES6+)

Довжина і доступ до символів

JavaScript
const str = 'Hello';

console.log(str.length);   // 5
console.log(str[0]);       // "H"
console.log(str.at(-1));   // "o" — ES2022, підтримує від'ємні індекси
console.log(str.at(0));    // "H"

// Рядки незмінні
str[0] = 'h'; // мовчки ігнорується
console.log(str); // "Hello"

Пошук

JavaScript
const text = 'The quick brown fox jumps over the lazy dog';

// indexOf / lastIndexOf — позиція або -1
console.log(text.indexOf('fox'));       // 16
console.log(text.indexOf('cat'));       // -1
console.log(text.lastIndexOf('the'));   // 31

// includes / startsWith / endsWith — булеве (ES6)
console.log(text.includes('fox'));           // true
console.log(text.startsWith('The'));         // true
console.log(text.endsWith('dog'));           // true
console.log(text.startsWith('quick', 4));   // true — другий аргумент: позиція

Вилучення підрядків

JavaScript
const str = 'JavaScript';

// slice(start, end) — від'ємні індекси підтримуються
console.log(str.slice(0, 4));    // "Java"
console.log(str.slice(4));       // "Script"
console.log(str.slice(-6));      // "Script" — від'ємний: з кінця
console.log(str.slice(4, -2));   // "Scri"

// substring(start, end) — від'ємні → 0, міняє місцями якщо start > end
console.log(str.substring(4, 0)); // "Java" — поміняло місцями
// slice рекомендований: більш передбачуваний

Трансформація

JavaScript
const s = '  Hello, World!  ';

// Регістр
console.log(s.toLowerCase());    // "  hello, world!  "
console.log(s.toUpperCase());    // "  HELLO, WORLD!  "

// Обрізання пробілів
console.log(s.trim());           // "Hello, World!"
console.log(s.trimStart());      // "Hello, World!  "
console.log(s.trimEnd());        // "  Hello, World!"

// Заміна
const text = 'foo foo foo';
console.log(text.replace('foo', 'bar'));     // "bar foo foo" — перше входження
console.log(text.replaceAll('foo', 'bar')); // "bar bar bar" — всі (ES2021)
console.log(text.replace(/foo/g, 'bar'));   // "bar bar bar" — regex

// Розбивка і з'єднання
const csv = 'a,b,c,d';
const arr = csv.split(',');           // ['a','b','c','d']
console.log(arr.join(' | '));         // "a | b | c | d"
console.log('abc'.split(''));         // ['a','b','c']

// Повторення і доповнення
console.log('ha'.repeat(3));          // "hahaha"
console.log('5'.padStart(4, '0'));    // "0005"
console.log('5'.padEnd(4, '-'));      // "5---"

Шаблонні літерали

JavaScript
const name    = 'Олена';
const balance = 1500.5;

// Інтерполяція виразів
const msg = `Вітаємо, ${name}! Баланс: ${balance.toFixed(2)} UAH`;

// Багаторядковість
const html = `
  <div class="card">
    <h2>${name}</h2>
  </div>
`;

// Tagged templates (просунуто)
function highlight(strings, ...values) {
  return strings.reduce((result, str, i) =>
    result + str + (values[i] !== undefined ? `**${values[i]}**` : ''), '');
}
console.log(highlight\`Hello ${name}, balance: ${balance}\`);
// "Hello **Олена**, balance: **1500.5**"

Підсумок

  • Рядки незмінні: всі методи повертають нові рядки.
  • Пошук: includes, startsWith, endsWith — булеве; indexOf — позиція або -1.
  • slice(start, end) — підтримує від'ємні індекси. Рекомендований над substring.
  • replaceAll (ES2021) — заміна всіх входжень без regex.
  • str.at(-1) — останній символ (ES2022).
  • Шаблонні літерали: багаторядковість, інтерполяція, tagged templates.
