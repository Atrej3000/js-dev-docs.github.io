Перетворення типів

Початковий Основи JavaScript ~ 13 хв

JavaScript виконує автоматичне (неявне) перетворення типів коли значення різних типів використовуються разом. Розуміння алгоритмів перетворення — ключ до передбачуваної поведінки операторів, умовних виразів і порівнянь.

Чому це важливо

Більшість дивних результатів у JavaScript ("5" - 2 === 3, але "5" + 2 === "52") є прямим наслідком неявного перетворення типів. Знання правил перетворення перетворює «магію» на передбачувану механіку.

Рядкове перетворення (ToString)

Відбувається при конкатенації з рядком або явному виклику String().

JavaScript
// Явне перетворення
String(123)        // "123"
String(-0)         // "0"
String(Infinity)   // "Infinity"
String(NaN)        // "NaN"
String(true)       // "true"
String(false)      // "false"
String(null)       // "null"
String(undefined)  // "undefined"
String([1, 2, 3])  // "1,2,3"
String({})         // "[object Object]"

// Неявне: конкатенація з рядком через +
console.log('value: ' + 42);        // "value: 42"
console.log('result: ' + null);     // "result: null"
console.log('flag: ' + true);       // "flag: true"
console.log(1 + 2 + ' items');      // "3 items" (зліва направо: 1+2=3, потім "3"+" items")
console.log('items: ' + 1 + 2);    // "items: 12" (рядок + число = конкат)

Числове перетворення (ToNumber)

Відбувається в арифметичних операціях (крім + з рядком), при явному виклику Number() або унарному +.

JavaScript
// Явне перетворення
Number(undefined)   // NaN
Number(null)        // 0
Number(true)        // 1
Number(false)       // 0
Number('')          // 0
Number(' ')         // 0   — пробіли обрізаються
Number('42')        // 42
Number('3.14')      // 3.14
Number('0xFF')      // 255
Number('12abc')     // NaN — містить нецифровий символ
Number([])          // 0   — порожній масив → "" → 0
Number([1])         // 1   — один елемент → "1" → 1
Number([1, 2])      // NaN — "1,2" → NaN
Number({})          // NaN

// Неявне: арифметичні операції
console.log('6' / '2');    // 3   — обидва перетворені
console.log('6' - 2);      // 4
console.log('6' * '3');    // 18
console.log(true + true);  // 2
console.log(false + 1);    // 1
console.log(null + 1);     // 1
console.log(undefined + 1);// NaN

// Унарний + — швидке перетворення до числа
const input = '42';
console.log(+input);  // 42
console.log(+true);   // 1
console.log(+null);   // 0
console.log(+'');     // 0

Булеве перетворення (ToBoolean)

Відбувається в умовних виразах (if, while, тернарний оператор) або при явному Boolean() чи !!.

Правило просте: є рівно 8 falsy-значень, все решта — truthy.

ЗначенняBoolean()
falsefalse
0false
-0false
0n (BigInt нуль)false
"" (порожній рядок)false
nullfalse
undefinedfalse
NaNfalse
Все рештаtrue
JavaScript
// Truthy-сюрпризи
Boolean('0')         // true  — непорожній рядок
Boolean('false')     // true  — непорожній рядок
Boolean([])          // true  — порожній масив є truthy!
Boolean({})          // true  — порожній об'єкт є truthy!
Boolean(-1)          // true  — будь-яке ненульове число

// Практичне застосування
const items = [];
if (items) {                    // true — перевірка масиву через truthy НЕПРАВИЛЬНА
  console.log('є елементи');   // виконується навіть для порожнього масиву!
}
if (items.length > 0) {        // ПРАВИЛЬНА перевірка
  console.log('є елементи');
}

// Подвійне заперечення — ідіоматичне перетворення в boolean
console.log(!!0);        // false
console.log(!!'hello');  // true
console.log(!!null);     // false
console.log(!![]);       // true

Перетворення об'єктів у примітиви

Коли об'єкт використовується там, де очікується примітив, рушій викликає внутрішню абстрактну операцію ToPrimitive. Алгоритм залежить від hint: "string", "number" або "default".

JavaScript
// Стандартна поведінка об'єктів
console.log({} + []);    // "0" або "[object Object]" (залежить від контексту)
console.log([] + []);    // ""
console.log([] + {});    // "[object Object]"

// Власне перетворення через Symbol.toPrimitive
const temperature = {
  celsius: 22,
  [Symbol.toPrimitive](hint) {
    if (hint === 'number') return this.celsius;
    if (hint === 'string') return `${this.celsius}°C`;
    return this.celsius; // default
  }
};

console.log(+temperature);          // 22  (number hint)
console.log(`${temperature}`);      // "22°C" (string hint)
console.log(temperature + 0);       // 22 (default hint)

Явні функції перетворення

ФункціяДо типуОсобливості
String(v)stringБезпечна для всіх значень
Number(v)numbernull→0, undefined→NaN
Boolean(v)boolean8 falsy значень
parseInt(v, radix)integerПарсить до першого нецифрового; radix обов'язковий
parseFloat(v)floatПарсить дробові числа
JavaScript
// parseInt зупиняється на першому нецифровому символі
parseInt('42px', 10)    // 42
parseInt('3.14', 10)    // 3 — відкидає дробову частину
parseInt('0xFF', 16)    // 255
parseInt('abc', 10)     // NaN

// Завжди вказуйте основу системи числення
parseInt('010')         // 10 (сучасні рушії) або 8 (legacy)
parseInt('010', 10)     // 10 — явно десяткова, надійно
parseInt('010', 8)      // 8  — явно вісімкова

parseFloat('3.14abc')   // 3.14
parseFloat('abc')       // NaN

Edge cases

JavaScript
// Несподіване поводження null і undefined
console.log(null + 1);       // 1  (null → 0)
console.log(undefined + 1);  // NaN (undefined → NaN)
console.log(null + '1');      // "null1" (рядкова конкатенація)

// Порожній масив
console.log(Number([]));     // 0
console.log(Number([1]));    // 1
console.log(Number([1,2]));  // NaN
console.log([] == false);    // true (обидва → 0)
console.log([] == ![]);      // true — відома аномалія

// String + Number: + є конкатенацією якщо один з операндів рядок
console.log(1 + '2');   // "12"
console.log('1' + 2);   // "12"
console.log(1 - '2');   // -1 — мінус завжди числовий
console.log(1 * '2');   // 2
console.log('3' ** 2);  // 9

Підсумок

  • Три напрямки перетворення: ToString, ToNumber, ToBoolean.
  • ToString: null→"null", undefined→"undefined", {}→"[object Object]", []→"".
  • ToNumber: null→0, undefined→NaN, ""→0, true→1, false→0, нецифровий рядок→NaN.
  • ToBoolean: falsy — false, 0, -0, 0n, "", null, undefined, NaN. Порожній [] і {} — truthy.
  • Оператор + з рядком → конкатенація. Усі інші арифметичні оператори → числове перетворення.
  • parseInt(str, 10) — завжди вказуйте основу. Парсить до першого нецифрового символу.
