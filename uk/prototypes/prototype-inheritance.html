Успадкування через прототипи

СереднійПрототипи, наслідування~ 14 хв

Прототипне успадкування — механізм за яким об'єкт може «успадковувати» властивості і методи від іншого об'єкта через ланцюг прототипів. Коли рушій шукає властивість — він піднімається по ланцюгу [[Prototype]] до null.

Ланцюг прототипів

JavaScript
const animal = {
  eats: true,
  walk() { console.log('Animal walk'); },
};

const rabbit = {
  jumps: true,
  __proto__: animal,   // встановлює [[Prototype]]
};

// rabbit успадковує від animal
console.log(rabbit.eats);  // true — не знайдено у rabbit → шукаємо у animal
console.log(rabbit.jumps); // true — знайдено у rabbit
rabbit.walk();             // "Animal walk" — успадкований метод

// Ланцюг може бути довшим
const longEarRabbit = {
  earLength: 10,
  __proto__: rabbit,
};
console.log(longEarRabbit.eats); // true — через rabbit → animal

Object.create

JavaScript
// Object.create(proto) — створює об'єкт з заданим прототипом
const animal = {
  breathes: true,
  describe() { return `I am ${this.name}`; },
};

const dog = Object.create(animal);
dog.name  = 'Rex';
dog.bark  = function() { return 'Woof!'; };

console.log(dog.breathes);     // true — з animal
console.log(dog.describe());   // "I am Rex" — this = dog
console.log(dog.bark());       // "Woof!"

// Object.create(null) — об'єкт без прототипу (чистий словник)
const dict = Object.create(null);
dict.key = 'value';
// dict.toString(); // TypeError — немає прotototype взагалі

// Перевірка прототипу
console.log(Object.getPrototypeOf(dog) === animal); // true

Shadowing: перекриття властивостей

JavaScript
const animal = {
  sound: 'generic sound',
  speak() { return `I say ${this.sound}`; },
};

const cat = Object.create(animal);
cat.sound = 'meow'; // перекриває animal.sound для cat

console.log(cat.speak());    // "I say meow" — this.sound = cat.sound
console.log(animal.speak()); // "I say generic sound" — animal не змінився

// Операції запису/видалення — завжди на власному об'єкті
cat.newProp = 'only on cat';
delete cat.sound;        // видаляє власну властивість
console.log(cat.sound);  // "generic sound" — знову з прotototype

hasOwn і for...in

JavaScript
const proto = { inherited: true };
const obj   = Object.create(proto);
obj.own = 'mine';

// for...in обходить ВСІ enumerable, включно з унаслідованими
for (const key in obj) {
  console.log(key); // "own", "inherited"
}

// Власні ключі
console.log(Object.keys(obj));         // ["own"] — лише власні
console.log(Object.hasOwn(obj, 'own'));        // true
console.log(Object.hasOwn(obj, 'inherited')); // false

Підсумок

  • Кожен об'єкт має внутрішній [[Prototype]]. Пошук властивості піднімається по ланцюгу.
  • Object.create(proto) — явне створення об'єкта з заданим прототипом.
  • Запис і видалення — завжди на власному об'єкті, не торкаються прotototype.
  • for...in обходить унаслідовані. Object.keys і Object.hasOwn — лише власні.
