Взаємодія: alert, prompt, confirm

Початковий Основи JavaScript ~ 7 хв

Браузер надає три вбудованих функції для синхронної взаємодії з користувачем через модальні вікна. Всі три є методами глобального об'єкта window і блокують виконання скрипта до закриття діалогу.

alert

Відображає модальне вікно з повідомленням і кнопкою «OK». Повертає undefined.

JavaScript
alert('Операцію завершено успішно');

// Аргумент перетворюється на рядок
alert(42);      // показує "42"
alert(null);    // показує "null"
alert();        // показує порожнє вікно (або "undefined" залежно від браузера)

// Повертає undefined
const result = alert('test');
console.log(result); // undefined

prompt

Відображає діалог із текстовим полем для введення. Повертає введений рядок або null (якщо користувач натиснув «Скасувати» або закрив вікно).

JavaScript
// prompt(message, default)
const name = prompt('Введіть ваше ім\'я:');
// Якщо OK → рядок (навіть порожній "")
// Якщо Cancel → null

const age = prompt('Введіть вік:', '18'); // другий аргумент — значення за замовчуванням

// Обов'язково перевіряйте на null перед використанням
if (name !== null) {
  console.log(`Привіт, ${name}!`);
} else {
  console.log('Введення скасовано');
}

// Конвертація: prompt завжди повертає рядок або null
const ageNum = Number(prompt('Вік:'));
if (Number.isNaN(ageNum)) {
  alert('Некоректне значення');
}
prompt завжди повертає string або null

Навіть якщо користувач вводить число, prompt повертає рядок. Завжди виконуйте явне перетворення: Number(), parseInt() або parseFloat().

confirm

Відображає діалог із питанням і кнопками «OK» / «Скасувати». Повертає true (OK) або false (Cancel).

JavaScript
const confirmed = confirm('Видалити запис? Цю дію не можна скасувати.');

if (confirmed) {
  deleteRecord();
} else {
  console.log('Видалення скасовано');
}

// Повертає булеве значення
console.log(typeof confirm('test')); // "boolean"

Обмеження браузерних діалогів

  • Блокування виконання. Всі три функції зупиняють JavaScript і рендеринг до закриття діалогу. Це неприйнятно у продакшені для будь-якої дії, крім критичних попереджень.
  • Зовнішній вигляд. Стиль діалогів визначає браузер — CSS застосунку на них не діє.
  • Заголовок. Деякі браузери додають «Сторінка каже:» або адресу сайту, що знижує довіру.
  • Відключення браузером. Якщо сторінка викликає діалоги занадто часто або всередині iframe, браузер може їх заблокувати.
  • Недоступні в Node.js. Ці функції — частина Browser API, не ECMAScript.
Де і коли доречні

Браузерні діалоги доречні лише для навчальних цілей або швидкого прототипування. У реальних застосунках використовуйте власні UI-компоненти: модальні вікна, тости, форми підтвердження.

Підсумок

  • alert(msg) — показує повідомлення, повертає undefined.
  • prompt(msg, default) — запитує введення, повертає string або null.
  • confirm(msg) — запитує підтвердження, повертає boolean.
  • Всі три блокують виконання. Зовнішній вигляд визначає браузер.
  • У продакшені замінюйте кастомними UI-компонентами.
