Ланцюжок промісів

СереднійПроміси, async/await~ 10 хв

Ланцюжок Promise — послідовне виконання асинхронних операцій без callback hell. Ключовий принцип: кожен .then() повертає новий Promise, і можна повертати як значення, так і Promise.

Що повертає .then()

JavaScript
// Повернення значення → наступний .then отримує його
Promise.resolve(1)
  .then(n => n + 10)      // повертає 11
  .then(n => n * 2)       // повертає 22
  .then(console.log);     // 22

// Повернення Promise → очікуємо його виконання
Promise.resolve('start')
  .then(val => {
    return new Promise(resolve => setTimeout(() => resolve(val + '_done'), 500));
  })
  .then(console.log); // 'start_done' — через 500ms

// Throw всередині .then → переходить у .catch
Promise.resolve('data')
  .then(data => {
    if (!data) throw new Error('empty');
    return data.toUpperCase();
  })
  .catch(console.error);

Реальний ланцюжок

JavaScript
// Послідовні fetch-запити
fetch('/api/user/1')
  .then(res => {
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return res.json();
  })
  .then(user => fetch(`/api/orders?userId=${user.id}`))
  .then(res => res.json())
  .then(orders => {
    console.log('Замовлення:', orders.length);
    return orders;
  })
  .catch(err => {
    console.error('Помилка:', err.message);
    return []; // відновлення
  });

Типові помилки

JavaScript
// ❌ Pyramid of doom з Promise (не ланцюжок!)
fetch('/api/user')
  .then(res => {
    fetch('/api/orders')     // ← не повертається!
      .then(r => r.json())
      .then(console.log);
  });

// ✅ Правильний ланцюжок
fetch('/api/user')
  .then(res => fetch('/api/orders')) // ← return
  .then(res => res.json())
  .then(console.log);

// ❌ Втрата помилки
promise
  .then(step1)
  .then(step2);   // якщо step1 кидає — step2 не виконається, але помилка втрачена

// ✅ Завжди .catch в кінці
promise
  .then(step1)
  .then(step2)
  .catch(handleError);

Підсумок

  • Завжди return Promise або значення з .then()
  • Якщо повертаєш Promise — ланцюжок чекає на його виконання
  • Не вкладай .then() всередину .then() — це callback hell у новому одязі
  • .catch() ловить помилки з усіх попередніх кроків
