Базові оператори, математика

Початковий Основи JavaScript ~ 12 хв

Оператори — синтаксичні конструкції, що виконують операції над значеннями (операндами). JavaScript має арифметичні, рядкові, унарні та бінарні оператори з чітко визначеним пріоритетом виконання.

Арифметичні оператори

JavaScript
console.log(10 + 3);   // 13  — додавання
console.log(10 - 3);   // 7   — віднімання
console.log(10 * 3);   // 30  — множення
console.log(10 / 3);   // 3.3333… — ділення (завжди float)
console.log(10 % 3);   // 1   — остача від ділення
console.log(2 ** 10);  // 1024 — піднесення до степеня (ES2016)

// Цілочисельне ділення — через Math.trunc
console.log(Math.trunc(10 / 3)); // 3

// Остача від ділення: знак результату — знак лівого операнда
console.log( 5 % 3);   //  2
console.log(-5 % 3);   // -2
console.log( 5 % -3);  //  2

Оператор + з рядками

Оператор + є перевантаженим: якщо хоча б один операнд є рядком — виконується конкатенація. У решті випадків — числове додавання.

JavaScript
// Числове додавання
console.log(1 + 2);         // 3

// Конкатенація: рядок + будь-що
console.log('1' + 2);       // "12"
console.log(1 + '2');       // "12"
console.log(1 + 2 + '3');   // "33" — зліва направо: 1+2=3, потім "3"+"3"="33"
console.log('1' + 2 + 3);   // "123"

// Числові оператори завжди конвертують до числа
console.log('6' - '2');     // 4
console.log('6' / '2');     // 3
console.log('6' * '2');     // 12

Унарні оператори

JavaScript
// Унарний плюс — конвертує до числа (аналог Number())
console.log(+'3');       // 3
console.log(+true);      // 1
console.log(+false);     // 0
console.log(+null);      // 0
console.log(+'');        // 0
console.log(+'abc');     // NaN

// Унарний мінус — змінює знак
console.log(-5);         // -5
console.log(-(-5));      // 5
console.log(-'3');       // -3 (конвертує і змінює знак)

Інкремент і декремент

Оператори ++ і -- збільшують або зменшують значення на 1. Префіксна форма повертає нове значення, постфіксна — старе.

JavaScript
let count = 5;

// Постфіксний: повертає СТАРЕ значення, потім збільшує
console.log(count++); // 5 — повернуто старе
console.log(count);   // 6

// Префіксний: спочатку збільшує, повертає НОВЕ значення
console.log(++count); // 7 — повернуто нове
console.log(count);   // 7

// Практичне правило: використовуйте окремим рядком
count++;
count--;
// Уникайте вбудовування в складні вирази — знижує читабельність

Пріоритет операторів

Пріоритет визначає порядок обчислення у виразі без дужок. Вищий пріоритет — виконується першим.

ПріоритетОператориАсоціативність
19( ) групування—
16** степіньСправа
15! + - унарніСправа
14* / %Зліва
13+ - бінарніЗліва
4= += -= …Справа
JavaScript
// Пріоритет без дужок
console.log(2 + 3 * 4);     // 14 — * виконується першим
console.log((2 + 3) * 4);   // 20 — дужки підвищують пріоритет

// Степінь — права асоціативність
console.log(2 ** 3 ** 2);   // 512 — 3**2=9, потім 2**9
// Лівоасоціативні оператори
console.log(100 / 10 / 2);  // 5 — (100/10)/2

// Присвоєння повертає значення (права асоціативність)
let a, b, c;
a = b = c = 5; // c=5, b=5, a=5
console.log(a, b, c); // 5 5 5

Оператори присвоєння

JavaScript
let x = 10;

x += 5;   // x = x + 5 → 15
x -= 3;   // x = x - 3 → 12
x *= 2;   // x = x * 2 → 24
x /= 4;   // x = x / 4 → 6
x %= 4;   // x = x % 4 → 2
x **= 3;  // x = x ** 3 → 8

// Логічне присвоєння (ES2021)
let a = null;
a ??= 'default';   // a = a ?? 'default' → 'default' (якщо null/undefined)

let b = 0;
b ||= 42;          // b = b || 42 → 42 (якщо falsy)

let c = 1;
c &&= 99;          // c = c && 99 → 99 (якщо truthy)

Побітові оператори

Оперують з 32-бітним цілочисельним представленням. Рідко використовуються в прикладному JS, але зустрічаються у низькорівневому коді та оптимізаціях.

JavaScript
// Побітове AND
console.log(5 & 3);   // 1  (101 & 011 = 001)

// Побітове OR
console.log(5 | 3);   // 7  (101 | 011 = 111)

// Побітове XOR
console.log(5 ^ 3);   // 6  (101 ^ 011 = 110)

// Побітове NOT (інвертує всі біти, включно зі знаком)
console.log(~5);      // -6 (еквівалент -(n+1))

// Зсув вліво / вправо
console.log(5 << 1);  // 10 (множення на 2)
console.log(5 >> 1);  // 2  (ділення на 2, зі знаком)
console.log(-5 >>> 1);// 2147483645 (беззнаковий зсув)

// Практичне застосування: перевірка парності
const isEven = n => (n & 1) === 0;
console.log(isEven(4)); // true
console.log(isEven(7)); // false

Оператор кома

Оператор кома обчислює кожен операнд зліва направо і повертає значення останнього. Найнижчий пріоритет серед усіх операторів. Використовується переважно в заголовку for.

JavaScript
// Повертає останнє значення
const result = (1, 2, 3);
console.log(result); // 3

// Використання в for-циклі
for (let i = 0, j = 10; i < 5; i++, j--) {
  console.log(i, j); // 0 10, 1 9, ...
}

Підсумок

  • Арифметика: + - * / % **. Ділення завжди повертає float.
  • + з рядком → конкатенація. Усі інші оператори (- * / %) → числове перетворення.
  • Унарний + — конвертує до числа. Унарний - — змінює знак.
  • Постфіксний x++ повертає старе значення. Префіксний ++x — нове.
  • ** — права асоціативність: 2 ** 3 ** 2 === 2 ** 9.
  • Логічне присвоєння ES2021: ??=, ||=, &&=.
