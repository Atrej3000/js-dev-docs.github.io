Копіювання об'єктів та посилання

ПочатковийОб'єкти: основи~ 13 хв

Примітиви зберігаються і копіюються «за значенням». Об'єкти — «за посиланням»: змінна зберігає не сам об'єкт, а адресу у пам'яті. Це фундаментальна відмінність, що впливає на рівність, копіювання і передачу аргументів.

Передача за посиланням

JavaScript
// Примітив: копія значення
let a = 10;
let b = a;
b = 20;
console.log(a); // 10 — a не змінилась

// Об'єкт: копія посилання
const user = { name: 'Олена', age: 28 };
const admin = user;    // admin і user посилаються на ОДИН об'єкт

admin.role = 'admin';  // мутуємо об'єкт через admin
console.log(user.role); // "admin" — user бачить зміну

// Перевірка посилань
console.log(user === admin); // true — одна адреса

const copy = { name: 'Олена', age: 28 };
console.log(user === copy);  // false — різні об'єкти

Поверхнева копія (Shallow Copy)

Поверхнева копія створює новий об'єкт із копіями значень верхнього рівня. Вкладені об'єкти залишаються посиланнями на ті ж самі об'єкти.

JavaScript
const original = {
  name:    'Laptop',
  price:   1200,
  specs:   { ram: 16, storage: 512 },  // вкладений об'єкт
  tags:    ['tech', 'sale'],            // вкладений масив
};

// Метод 1: Object.assign
const copy1 = Object.assign({}, original);

// Метод 2: Spread (рекомендований)
const copy2 = { ...original };

// Тест поверхневості
copy2.name = 'Tablet';       // OK — примітив скопійований
copy2.specs.ram = 32;        // МУТУЄ оригінал — specs — посилання!

console.log(original.name);      // "Laptop"  — не змінився
console.log(original.specs.ram); // 32 — ЗМІНИВСЯ!

// Те саме з масивами
copy2.tags.push('new');
console.log(original.tags); // ['tech', 'sale', 'new'] — мутовано!

Глибока копія (Deep Copy)

Глибока копія рекурсивно клонує всі вкладені об'єкти і масиви. Оригінал і копія повністю незалежні.

structuredClone (ES2022) — рекомендований спосіб

JavaScript
const original = {
  name:  'Config',
  meta:  { version: 2, tags: ['a', 'b'] },
  date:  new Date('2024-01-01'),
  data:  new Uint8Array([1, 2, 3]),
};

const deep = structuredClone(original);

deep.meta.version = 99;
deep.meta.tags.push('c');

console.log(original.meta.version); // 2  — незмінний
console.log(original.meta.tags);    // ['a', 'b'] — незмінний
console.log(deep.date instanceof Date); // true — Date клонується

// structuredClone підтримує: Date, RegExp, Map, Set, ArrayBuffer,
// TypedArray, Error, циклічні посилання
// НЕ підтримує: функції, DOM-вузли, Symbol-ключі

JSON.parse/stringify — з обмеженнями

JavaScript
const data = { name: 'test', nested: { value: 42 } };
const deepCopy = JSON.parse(JSON.stringify(data));

// ОБМЕЖЕННЯ:
const problematic = {
  fn:        () => {},           // → втрачається (undefined)
  date:      new Date(),         // → рядок (не Date об'єкт)
  undef:     undefined,          // → втрачається
  nan:       NaN,                // → null
  infinity:  Infinity,           // → null
  map:       new Map(),          // → {} (порожній об'єкт)
  regexp:    /test/g,            // → {} (порожній)
  circular:  null,               // циклічне посилання → TypeError
};

// Використовуйте JSON.parse/stringify ТІЛЬКИ для простих JSON-сумісних структур

Передача об'єктів у функції

JavaScript
// Функція отримує посилання — може мутувати оригінал
function addRole(user) {
  user.role = 'admin'; // МУТУЄ оригінал
}

const person = { name: 'Андрій' };
addRole(person);
console.log(person.role); // "admin" — мутація відбулася

// Захист від мутацій: передавати копію або повертати новий об'єкт
function addRolePure(user) {
  return { ...user, role: 'admin' }; // не мутує вхід
}

const personClean = { name: 'Андрій' };
const adminUser = addRolePure(personClean);
console.log(personClean.role); // undefined — оригінал чистий
console.log(adminUser.role);   // "admin"

const і мутабельність

JavaScript
// const забороняє переприсвоєння посилання, але не мутацію об'єкта
const config = { port: 3000 };

config.port = 8080;    // OK — мутація об'єкта
config.host = 'prod';  // OK — додавання властивості

// config = {};        // TypeError — переприсвоєння заборонено

// Для справжньої незмінності — Object.freeze
const frozen = Object.freeze({ port: 3000, host: 'local' });
frozen.port = 9000;    // мовчки ігнорується (TypeError у strict mode)
console.log(frozen.port); // 3000

// Freeze — поверхневе!
const obj = Object.freeze({ nested: { value: 1 } });
obj.nested.value = 99; // дозволено — nested не заморожений
console.log(obj.nested.value); // 99

Підсумок

  • Об'єкти передаються за посиланням. Присвоєння копіює адресу, не значення.
  • Два об'єкти з однаковим вмістом !== — вони різні адреси в пам'яті.
  • Shallow copy ({ ...obj }, Object.assign): вкладені об'єкти залишаються посиланнями.
  • structuredClone — глибока копія, підтримує Date/Map/Set/TypedArray. Не підтримує функції.
  • JSON.parse/stringify — лише для JSON-сумісних структур. Втрачає функції, Date, undefined, NaN.
  • const не захищає від мутацій. Object.freeze — поверхневе заморожування.
  • Чисті функції не мутують вхідні аргументи — повертають нові об'єкти.
