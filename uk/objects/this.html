Методи об'єкта, this

ПочатковийОб'єкти: основи~ 14 хв

Метод — функція, що є властивістю об'єкта. Ключове слово this всередині методу посилається на об'єкт, через який був зроблений виклик. Значення this визначається у момент виклику, а не у момент оголошення функції.

Оголошення методів

JavaScript
const user = {
  name:  'Олена',
  age:   28,

  // Скорочений синтаксис (рекомендований)
  greet() {
    return `Привіт, мене звати ${this.name}`;
  },

  // Функціональний вираз (еквівалентно)
  getAge: function() {
    return this.age;
  },
};

console.log(user.greet());   // "Привіт, мене звати Олена"
console.log(user.getAge());  // 28

this — динамічний контекст

Значення this залежить від того, як викликана функція, а не де вона оголошена.

JavaScript
function showName() {
  console.log(this.name);
}

const alice = { name: 'Alice', show: showName };
const bob   = { name: 'Bob',   show: showName };

alice.show(); // "Alice" — this = alice
bob.show();   // "Bob"   — this = bob

// Та сама функція — різні this залежно від об'єкта виклику

Втрата контексту this

Найпоширеніша пастка: метод присвоєний змінній або переданий як callback — втрачає зв'язок з об'єктом.

JavaScript
const counter = {
  count: 0,
  increment() { this.count++; },
};

counter.increment(); // OK — this = counter
console.log(counter.count); // 1

// ВТРАТА: присвоєння виривє метод з об'єкта
const fn = counter.increment;
fn(); // this = undefined (strict) або globalThis (sloppy)
// counter.count залишається 1

// Типова пастка — передача в callback
setTimeout(counter.increment, 100);
// Через 100ms: this не є counter → count не зростає

// РІШЕННЯ 1: стрілкова функція-обгортка
setTimeout(() => counter.increment(), 100); // OK

// РІШЕННЯ 2: bind — фіксує this
const boundIncrement = counter.increment.bind(counter);
setTimeout(boundIncrement, 100); // OK

this без контексту

JavaScript
"use strict";

function standalone() {
  console.log(this); // undefined у strict mode
}
standalone(); // undefined

// У sloppy mode: this = globalThis (window у браузері)
// Ще одна причина завжди використовувати "use strict"

call, apply, bind

JavaScript
function introduce(greeting, punctuation) {
  return `${greeting}, я ${this.name}${punctuation}`;
}

const person = { name: 'Андрій' };

// call: явний this + аргументи через кому
introduce.call(person, 'Привіт', '!'); // "Привіт, я Андрій!"

// apply: явний this + аргументи масивом
introduce.apply(person, ['Добрий день', '.']); // "Добрий день, я Андрій."

// bind: повертає нову функцію з фіксованим this
const boundIntro = introduce.bind(person, 'Привіт');
boundIntro('!');  // "Привіт, я Андрій!"
boundIntro('?');  // "Привіт, я Андрій?"

Ланцюговий виклик методів

JavaScript
// Методи повертають this для можливості ланцюга
class Builder {
  constructor() { this.steps = []; }
  add(step) { this.steps.push(step); return this; }
  build()   { return this.steps.join(' → '); }
}

const result = new Builder()
  .add('parse')
  .add('validate')
  .add('transform')
  .build();

console.log(result); // "parse → validate → transform"

Підсумок

  • Метод — функція як властивість об'єкта. Скорочений синтаксис method() {} — стандарт.
  • this визначається у момент виклику: obj.method() → this = obj.
  • Присвоєння методу змінній або передача як callback — втрата this.
  • Рішення: стрілкова функція-обгортка або .bind(obj).
  • call(ctx, ...args), apply(ctx, [args]) — явний this при виклику.
  • bind(ctx) — повертає нову функцію з постійним this.
