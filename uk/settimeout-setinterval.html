Планування: setTimeout та setInterval

ПочатковийФункції~ 14 хв

setTimeout і setInterval — функції Web API браузера і Node.js для планування виконання коду в майбутньому. Вони взаємодіють з подієвим циклом (event loop) і не є частиною специфікації ECMAScript.

setTimeout

JavaScript
// setTimeout(callback, delay, ...args)
// Виконує callback один раз через delay мілісекунд
const timerId = setTimeout(() => {
  console.log('Через 1 секунду');
}, 1000);

// Скасування до виконання
clearTimeout(timerId);

// Передача аргументів
setTimeout((name, greeting) => {
  console.log(`${greeting}, ${name}!`);
}, 500, 'Олена', 'Привіт');

// Затримка 0 — не означає "зараз"
setTimeout(() => console.log('B'), 0);
console.log('A');
// Виведе: A, потім B
// setTimeout 0 → кінець поточної черги задач

setInterval

JavaScript
// Виконує callback кожні delay мілісекунд
let count = 0;
const intervalId = setInterval(() => {
  count++;
  console.log(`Tick ${count}`);
  if (count >= 3) clearInterval(intervalId);
}, 1000);
// Tick 1 (через 1с)
// Tick 2 (через 2с)
// Tick 3 (через 3с, зупиняється)

// ВАЖЛИВО: завжди зберігайте timerId для clearInterval
// Забутий setInterval — витік пам'яті і CPU

Вкладений setTimeout vs setInterval

JavaScript
// setInterval: виконання може нагромаджуватись якщо callback > delay
// Вкладений setTimeout: гарантує паузу між виконаннями

// setInterval — можлива проблема
setInterval(heavyTask, 100); // якщо heavyTask займає >100ms — перекриття

// Вкладений setTimeout — безпечніше
function schedule() {
  heavyTask();
  setTimeout(schedule, 100); // наступний виклик ПІСЛЯ завершення поточного
}
setTimeout(schedule, 100);

setTimeout і event loop

JavaScript
// Порядок виконання
console.log('1 - синхронно');

setTimeout(() => console.log('3 - macrotask'), 0);

Promise.resolve().then(() => console.log('2 - microtask'));

console.log('1.5 - теж синхронно');

// Виведе:
// 1 - синхронно
// 1.5 - теж синхронно
// 2 - microtask (мікрозадачі виконуються до макрозадач)
// 3 - macrotask

Підсумок

  • setTimeout(fn, delay) — один виклик. clearTimeout(id) — скасування.
  • setInterval(fn, delay) — повторний. clearInterval(id) — зупинка. Завжди зберігайте id.
  • Затримка 0 не означає «зараз» — означає «після поточної задачі».
  • Вкладений setTimeout точніший за setInterval при довгих callback-ах.
  • setTimeout/setInterval — макрозадачі. Promise.then — мікрозадачі. Мікрозадачі виконуються першими.
