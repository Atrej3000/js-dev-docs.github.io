Ітеровані об'єкти

ПочатковийТипи даних~ 10 хв

Ітерований об'єкт (iterable) — будь-який об'єкт, який можна перебрати оператором for...of. Вбудовані ітерабельні: рядки, масиви, Map, Set, arguments, NodeList. Основа — символьний метод [Symbol.iterator]().

Протокол ітерації

Об'єкт є ітерабельним, якщо він містить метод [Symbol.iterator], що повертає ітератор — об'єкт з методом next(). Метод next() повертає { value, done }.

JavaScript
// Ітератор вручну
const range = {
  from: 1, to: 3,
  [Symbol.iterator]() {
    let cur = this.from;
    const last = this.to;
    return {
      next() {
        return cur <= last
          ? { value: cur++, done: false }
          : { value: undefined, done: true };
      }
    };
  }
};

for (const n of range) console.log(n); // 1 2 3
console.log([...range]);               // [1, 2, 3]
const [a, b] = range;                  // деструктуризація

Рядок як ітерабельний

JavaScript
for (const ch of 'hello') console.log(ch); // h e l l o

// Рядок ітерує по Unicode-codepoint, а не байтах
const emoji = '😀👍';
console.log([...emoji].length); // 2 (не 4!)
console.log(emoji.length);      // 4 — UTF-16 пари

Array-like vs Iterable

Array-like має length і числові індекси, але може не мати [Symbol.iterator]. Iterable має ітератор, але може не мати length. Масиви — і те, і інше.

JavaScript
// Array-like — не iterable!
const arrayLike = { 0: 'a', 1: 'b', length: 2 };
// for (const x of arrayLike) {}  // TypeError!

// Конвертація через Array.from
const arr = Array.from(arrayLike); // ['a', 'b']
Array.from(arrayLike, x => x.toUpperCase()); // ['A', 'B']

Власний ітератор із замиканням

JavaScript
// Генератор як ітератор (спрощена форма)
function* fibonacci() {
  let [a, b] = [0, 1];
  while (true) {
    yield a;
    [a, b] = [b, a + b];
  }
}

const fib = fibonacci();
console.log(fib.next().value); // 0
console.log(fib.next().value); // 1
console.log(fib.next().value); // 1
console.log(fib.next().value); // 2

// Перші 6 чисел Фібоначчі
import { take } from 'lodash'; // або вручну
const first6 = [];
for (const n of fibonacci()) {
  if (first6.length === 6) break;
  first6.push(n);
}
console.log(first6); // [0,1,1,2,3,5]

Spread і деструктуризація

JavaScript
// Spread розгортає iterable
const set = new Set([1, 2, 3]);
const arr = [...set];          // [1, 2, 3]
const combined = [...arr, ...set]; // [1,2,3,1,2,3]

// Деструктуризація iterable
const [first, second] = new Set([10, 20, 30]);
console.log(first, second); // 10 20

// Promise.all, Array.from, Map/Set constructor — всі приймають iterable
const map = new Map([['a', 1], ['b', 2]]);
const keys = [...map.keys()]; // ['a', 'b']

Підсумок

  • Iterable — має [Symbol.iterator](), працює з for...of, spread, деструктуризацією
  • Iterator — об'єкт з next() → {value, done}
  • Array.from(iterable) — конвертація у масив
  • Генератори — найзручніший спосіб створювати власні ітератори
  • Array-like ≠ iterable; Array.from обробляє обидва
